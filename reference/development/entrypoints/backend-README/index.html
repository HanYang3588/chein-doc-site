Chein 管理后端

backend/app 提供 FastAPI 管理 API。Platform 负责认证、租户、权限和基础设施；app/modules/items 与 app/modules/erp 是业务模块。Agent 执行运行时位于独立的 agent/，浏览器经后端 Agent UI BFF 访问。

本地运行​

先按本地启动配置 Nacos、数据库和 Edition，再从仓库根目录运行：

pnpm backend:dev

API 基础路径是 /api/v1；开发时可访问 OpenAPI UI、OpenAPI JSON 和 健康检查。监听端口不代表数据库与 Redis 已就绪，应检查健康状态。

常用验证​

pnpm backend:lint
pnpm backend:test

迁移与初始化顺序见后端启动和 Nacos；模块接入、Tenant UoW、RLS 和 Outbox 的边界见模块开发指南及后端规范。
