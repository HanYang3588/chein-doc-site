HermiT 计算服务设计

设计先于业务实现；兼容性实测、交付状态见验证记录。本任务明确要求独立服务，作为现有“不再拆业务微服务”基线的受控计算例外，见 ADR-0015（Proposed，未代替团队签署）。

2026-10-27 增量：版本化 OWL TBox 规则、校验任务发布门禁、授权 ERP 子图快照、统一 MCP 推理入口、任务面板和失败保护见集成设计及交付记录。下文“第一阶段”是原基础交付边界；全库/组织 ABox 仍关闭，Neo4j 与 n10s 基础推理的职责不变。

当前事实与职责​

本次分析开始前仓库没有 Java 项目。管理端是 React/Umi，Backend 是 Python 3.14/FastAPI/SQLModel，Agent 是独立 Python 3.13。app/api/deps.py 以 HS256 登录 JWT 查 UserSession、当前成员和租户，注销/过期不是仅验签能替代。app/platform/agent_delegation.py 已有短期 Ed25519 服务 delegation，Java 复用同一签名模式，专用 audience，不接受登录 JWT。

modules/ontology 在 PostgreSQL 拥有 Network/Version/Audit，私有/租户范围受 OntologyUnitOfWork 和 RLS 保护；ERP 是实时实例所有者。runtime.authorized_snapshot 重验当前发布版本、映射指纹与 Knowledge 来源。Neo4j 只投影授权发布的受限类/属性映射；n10s 类继承查询不能当作完整 OWL 2 DL。当前 semantics.py 拒绝等价类、属性链等超出声明的公理，semantic_worker.py 隔离 RDF/SHACL，不能扩宽该已发布 Schema 来冒充完整 OWL。

Nacos 已使用 CHEIN Group 和 bootstrap/runtime Data ID，官方 Python SDK 提供注册；文档记录 Server 3.2.4，真实 Java 注册另行实测。仓库没有可证明已部署的 Higress 业务入站认证配置；已有模型 Higress 说明不能视为用户鉴权已打通。Compose 依赖外置 PG/Redis/Nacos，不应创建替代中间件。

Java 无用户、角色、部门数据库，无 ERP/Neo4j 凭据，无 Python/Agent 框架依赖。Ontology 业务定义和 ACL 不迁出单体。计算任务状态由 Java 私有卷拥有，不是第二个业务调度系统；不增加 Kafka/RocketMQ。已有 Agent Automations 和 Creation Job 有各自业务所有权，不能跨模块复用其队列。

输入与语义范围​

正式入口为 Backend /api/v1/ontology/reasoner/jobs，输入二选一：当前已授权发布版本引用，或本人提交的有界内联 OWL 文件正文。版本入口导出既有受限 TBox（复用隔离 semantic export），明确它不是完整 OWL 的无损存储。上传可执行完整 OWL 2 DL，但只归本次私有计算，不发布、不与本体版本正文混存。支持 RDF/XML、Turtle、Functional Syntax；明确 format 与实际解析必须一致，拒绝其他解析器和 SWRL。

第一阶段不从 Neo4j 全图导出 ABox，不绕开 ERP 数据权限。已有实例映射只在数据所有者逐次授权的路径使用；需要 OWL ABox 的场景由用户上传当前允许的数据或后续受控导出器接入。TBox 与 ABox IRI 必须稳定；结果同时含 inputDigest、definitionDigest、ontologyVersion、engineVersion，不能与实时 ERP 快照混称。

操作：consistency、subclasses、superclasses、equivalents、unsatisfiable、instances、types、property-values、entailment（固定 typed axiom，不接受脚本）。层次/类型支持 direct。先检查一致性，不一致仍可成功返回 consistent=false；其他推理查询在不一致时返回明确错误，不把解析/超时当作 false。不可满足类与不一致区分；开放世界下未蕴含不代表业务否定，OWL 没有默认唯一名称假设。

结果是查询结果，携带 queried/asserted 区分信息；不声称全量新推导公理或自然语言解释。导出 JSON 或有界查询结果图 Turtle/RDFXML，明确该图不是完整本体或完整物化。默认无任何 Neo4j 写回，也不自动接入所有 Agent 请求。

任务与资源​

单实例一个计算 Worker，最多四个排队任务；默认 30 秒强制墙钟超时、输入 1 MiB、公理 20000、实体结果 500（分页 100）、Worker 堆 512 MiB，控制 JVM 堆 256 MiB，Compose 总内存 2 GiB/1 CPU。每任务启动独立 JVM，超时/取消杀死进程及子进程并等待退出，不能仅依赖线程中断。预算可在部署启动时配置并有上下限，变更需要重启。复杂 OWL 即使小文件也可能超预算。

任务状态 PENDING/RUNNING/SUCCEEDED/FAILED/CANCELLED/TIMED_OUT，原子元数据落盘后才确认提交；输入/结果私有卷，UUID 受控路径和原子替换。提交用 Idempotency-Key，键绑定 tenant/owner 与内容摘要，重用不同请求返回 409；不自动重试不明提交。终态不可被迟到完成覆盖；取消与完成用同一任务锁串行化。启动时未完成任务标记 FAILED/restarted，不自动重复推理。卷级排他锁禁止共享卷多副本；多机水平扩容须先迁移任务存储及抢占协议，当前不宣称支持。有限磁盘/任务保留和 TTL 清理，无无限缓存。状态落盘失败关闭新任务接入；取消即使写状态失败也终止 Worker，未持久化的成功状态不能冒充已确认完成。

设计自检​

不新增业务模块/Edition，不移动 PG 定义/ACL，不导入可选模块私有实现；查询/取消/导出均本人范围和当前版本校验，修改发布版本后旧结果不再放行。未知身份、无签名、伪造 header、关闭配置、缺签名材料均拒绝。文件和版本二选一，受限 TBox 不伪装完整 OWL。Nacos/Higress 断连不是授权放行理由。迁移影响为零表迁移；回滚为关闭 Backend reasoner 开关，保留私有卷；原有 Neo4j/Legacy/SHACL 路径保持。

实现位置与替换边界​

HTTP/错误映射在 ReasonerController，服务身份在 AuthBoundary，任务/子进程/持久化在 JobStore，OWL加载与 HermiT 在 HermitEngine，纯计算进程入口为 WorkerMain，官方注册配置在 NacosLifecycle。Backend 源/版本授权与导出位于 modules/ontology/application/reasoner.py，固定端点/短期签名位于 infrastructure/reasoner_client.py。公开 DTO 与源 OpenAPI 生成现有客户端；无新 Edition 模块或业务表。

只有一个引擎，不增加空的单实现接口或运行时插件加载器。将来引入第二个引擎时，在 HermitEngine.execute(Request, limits) 的有界结果契约与 Worker 调度边界接入固定实现，并分别测试其可支持的 OWL Profile；不能假定 ELK 等引擎与 HermiT 语义等价，也不能故障后混合结果。
