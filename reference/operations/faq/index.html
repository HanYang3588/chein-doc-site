常见问题

启动时报 Nacos 配置不存在​

先在 Nacos 的 CHEIN Group 中创建 chein-backend-bootstrap.yaml 和 chein-backend-runtime.yaml；模板在 deploy/nacos/。根目录 .env 只需要填写 Nacos 的地址、账号、密码和 namespace。

如何启动本地 PostgreSQL​

如果使用 Scoop 安装 PostgreSQL，可检查 PGDATA 并启动：

pg_ctl status -D $env:PGDATA
pg_ctl start -D $env:PGDATA -l "$env:PGDATA\postgresql.log"

前端菜单不显示​

默认 React 应用从 /menus/me 加载菜单。除角色/菜单权限外，还要检查 Manifest 是否兼容、当前 Edition 是否包含模块、模块访问状态及 Workspace.tsx 是否有受控 component 映射。后端 .vue key 是兼容标识，不是要求前端存在同名 Vue 文件。详见前端架构。

API 类型没有更新​

在仓库根目录，确认后端代码/依赖/配置和目标 Edition，再运行：

pnpm generate:api -- --edition suite

根生成器从后端组合导出临时 Schema，不通过 8000 端口读取，且会为各次子契约生成设置输入；不要用旧进程或模板 oneapi.json 作为事实源。React 输出在 web-pro/src/services/generated 和模块 api/generated，禁止手工补丁。

frontend:e2e 通过是否代表浏览器流程通过​

不是。当前该根脚本执行 React vitest run，只证明对应测试；真实后端、浏览器、租户权限、 ERP 单据和 Agent SSE 流程仍需另行验证。
