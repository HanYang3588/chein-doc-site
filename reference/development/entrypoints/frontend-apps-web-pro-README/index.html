Chein Ant Design Pro 前端

@chein/web-pro 是 Chein 默认的管理应用，采用 React 19、Umi Max 4、TypeScript、Ant Design 6 和 ProComponents 3；Agent 工作区使用 assistant-ui。

在仓库根目录使用以下命令：

pnpm frontend:dev
pnpm frontend:typecheck
pnpm frontend:pro:test
pnpm frontend:build

开发服务使用端口 5174；生产构建产物位于本应用的 dist 目录。请求使用同源 FastAPI /api/v1；Agent 请求使用 /api/v1/agent-ui。

参见前端架构、本地开发、Agent UI 设计和迁移与验收范围。旧 Vue 应用已从工作区移除。

生成的客户端位于 src/services/generated 和 src/modules/*/api/generated；src/runtime/build-manifest.ts 也由工具生成。请在仓库根目录通过 pnpm generate:api -- --edition <edition> 更新，不要使用上游模板的 openapi 脚本或 config/oneapi.json。

frontend:e2e 当前是 Vitest 的别名，不能证明已覆盖浏览器 E2E 测试。 简体中文
