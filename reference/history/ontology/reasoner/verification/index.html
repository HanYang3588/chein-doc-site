HermiT 本地验证与性能记录

状态：本地实现及隔离集成验证通过，正常部署默认关闭；远端 CI、生产运维/安全/法务与 ADR 治理未签署。设计在代码前写入，历史设计不替代下列执行证据。

构建与真实语义​

环境：macOS ARM，Maven3.9.9，显式 JAVA_HOME 的 GraalVM21.0.3；Docker 运行 Temurin21 JRE Jammy 固定 digest（见 Dockerfile）。本机旧补丁 JDK 仅用于兼容性验证。Boot3.5.16、OWLAPI5.5.1、HermiT1.4.5.519、Nacos client3.2.4 的仓库外探针及正式服务均运行真实推理。

mvn -B -f services/chein-reasoner/pom.xml verify：21项，20通过，1项 Nacos 外部测试默认跳过，0失败。覆盖真实类继承/等价/不相交/不可满足与不一致、数据类型限制、实例、逆/传递属性、属性链、蕴含、三种格式、开放世界与无唯一名称假设。任务测试另注入状态落盘失败，确认取消仍强杀真实子进程、关闭新任务接入；落盘未确认的成功状态不保留为成功。任务测试使用真实子JVM验证队列429、幂等/冲突、取消/重启/独占卷和超时；超时场景对已生成的本机子进程 SIGSTOP，验证到期强杀并回收，避免依赖“计算应该足够慢”的不确定断言。HTTP测试真实 Spring 随机端口，覆盖无凭证401、scope403、owner/tenant404、伪造身份头、签名 method/path/body 绑定和结果/导出。

Backend 在 backend/scripts/test_creation_isolated.py 新建的一次性数据库内串行执行：

cd backend
CHEIN_REASONER_JAVA_HOME=<jdk21> uv run python scripts/test_creation_isolated.py \
 tests/modules/ontology/test_reasoner_guards.py \
 tests/modules/ontology/test_reasoner_live.py \
 tests/modules/ontology/test_semantics.py tests/modules/test_module_boundaries.py -q --tb=short

结果 33 passed / 8 warnings / 88.83s。包含真实 app_runtime + Java、已发布 Neo4j 工作区语义版本导出、当前资源/来源权限、源版本变更撤销、跨owner/tenant、已有 UserSession 的 BFF 路由与角色权限撤销。交互式登录验证码流程没有重测，采用合法合成 Session 进入现有验证链；没有禁用验证码或绕开登录验证。8个警告来自 pytest重写和现有 Alembic path_separator。正常业务数据库没有运行清理 fixture。收尾再运行无DB fixture的 test_reasoner_guards.py：15通过，补充证明无效签名材料返回安全503，不泄露内容。

uv run ruff check app tests ../services/chein-reasoner/scripts、pnpm generate:api -- --edition suite、pnpm frontend:typecheck 均通过。base/items/suite 分别完成 pnpm build:edition -- --edition <edition>，保留最终 suite 生成输出；无前端新页面。内部 OpenAPI3.1 经 openapi-pydantic、JSON Schema与本地引用校验，Higress YAML 解析通过。新增功能无PG schema迁移。Docker 构建上下文只允许 JAR、许可证及声明，排除私有运行任务目录；镜像保留额外 THIRD-PARTY 与许可证正文。

依赖、安全与未执行门禁​

基础交付时已生成 CycloneDX 1.6 SBOM（155组件），按Maven包/版本查询OSV。初次命中旧Jackson/Tomcat/OTel/HTTP等依赖后在新服务独立BOM修复，再通过全部Java/HTTP/镜像测试。最终仍命中 Spring WebMVC6.2.19 两项：

  • GHSA-j9f9-w8pj-32f8：SSE fragment rendering。当前全部业务为结构化JSON/ResponseEntity，没有SSE片段视图路径。
  • GHSA-pc63-qcmh-9cmg：XsltView路径限制。当前没有XSLT视图/模板入口。

上面是当前代码的可达性判断，不是独立安全审计通过或零漏洞声明。查询时Maven Central公开6.2系列最高6.2.19，未盲升Spring7/Boot4来绕过兼容要求；安全负责人需复核可达性、接受/拒绝剩余风险并持续跟进修复。HermiT发行包老旧及LGPL分发义务独立列于技术选择和THIRD-PARTY。完整OS/镜像CVE扫描、镜像签名、远端CI、许可证/对应源码审阅、生产Nacos认证/网关/TLS与密钥轮换、Ubuntu目标架构断网演练、真实ERP规模评测及团队签署未执行。

SBOM插件要求在线模式：本次将它与 mvn -o verify 分开运行成功；不能把SBOM联网失败误报为离线构建失败，也不承诺首次无缓存可以离线构建。未增加自动Neo4j写回、全图库ABox抽取、新管理后台或默认Agent推理；它们是明确边界，不以占位实现冒充交付。
