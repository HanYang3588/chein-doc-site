Memory 治理方案历史与替代

2026-10-27：原 2026-10-22 方案已被 Native Memory 当前设计替代。本文保留决策演变，不作为现行开发规范。

旧方案使用规则和 System One 判断记忆价值，仅将用户证据封装后提交，助手回复为空；提取后再批准具体 ID，且等待用户离开会话才开始提交。它限制了完整问答同步，并增加了两层模型判断、超时及维护成本。对应治理分类器、评测运行器及其固定标签样例已从当前运行代码移除；历史 SQL migration 不改写。

用户现已明确选择由 RAGFlow 官方默认能力提取、按成功轮次同步完整问答。当前链路不再做上述价值筛选、冲突合并或离开门槛；不自动回放已终止的旧任务。老批准记录按已有私有范围兼容，其余旧来源不因升级无条件获得召回资格。详细协议、来源授权、部署兼容及官方限制统一见当前设计与 交付记录。

RAGFlow 能自动提取，不等于保证有用性、真实性或语义去重。Chein 保留 opt-in、租户/owner 隔离、当前权限、来源墓碑、删除、历史恢复校验及不明提交不重试；这些保护不属于价值筛选。
