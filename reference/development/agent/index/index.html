全局思想​

数据分析是稳定业务能力 analysis.v1。可替换的是实现它的技术栈：Deep Agents、AgentScope、LangGraph、LangChain、远程 Agent 或自研 Harness 都必须实现同一套业务契约、权限边界、事件语义和结果校验。

设计借鉴 Anthropic Managed Agents 的 session、harness、sandbox 分离：Session 保存可审计事件，Harness 负责无状态编排，Sandbox 提供隔离执行环境。模型、工具、数据、检索和沙箱都通过 Provider 与 Gateway 接入，模型不能直接接触数据库、凭据或任意工具。

Backend 负责身份、租户、RBAC 和授权 BFF；Agent 执行面负责模型循环、Provider 编排、运行状态、审批恢复、Token 计量和额度执行；ERP/Platform 是数据与权限事实源。部署可同机或分进程，边界和授权不随部署方式改变。

稳定面与可替换面​

稳定面可替换面
analysis.v1、QuerySpec、Snapshot、Report/CitationHarness、状态机和框架

ToolDescriptor、Provider DTO、错误码ERP、RAGFlow、MCP、HTTP、沙箱实现

“无损切换”指业务契约、权限范围、数值、引用和状态可验证地兼容，不要求自然语言逐字相同。Run 创建时固定 engine、model、toolset、workflow、policy 和 dataset 版本；旧 Run 不因新适配器发布而静默换引擎。
