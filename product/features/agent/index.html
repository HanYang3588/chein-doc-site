Agent 对话与业务分析

Agent 在当前账号获准的工具和数据范围内回答问题、检索资料、分析数据，并展示来源或结构化结果。问题越明确，越容易核对结果；例如说明业务对象、时间范围、指标与分组。

完成一次分析​

  1. 打开 Agent 页面并新建会话，确认当前租户。
  2. 提出问题，例如“按月份汇总我有权查看的销售数据，说明时间范围和金额口径”。
  3. 查看工具事件、引用与图表。需要澄清或审批时，按页面提示处理。
  4. 核对结论与来源；图表收藏的操作见常见操作。

生成答案不能替代业务原始单据，图表只覆盖已授权范围。工具失败、来源撤销或证据不足时，应按错误提示处理。

在对话中使用业务本体​

输入框旁的“本体与决策”提供业务本体和决策模型偏好。设置作用于下一次新运行；恢复已有运行沿用原设置。开关开启表示允许使用，实际调用还取决于工具目录、服务配置和当前权限。

本体可以帮助 Agent 找到业务概念、关系与获准推导。理解结论时，请查看实际工具事件和证明；需要 ERP 写操作时仍由业务页面完成。先读本体与业务结合，配置细节见对话控制。

会话、记忆与用量​

会话历史用于继续当前任务；长期记忆是独立能力，按个人范围授权。启用自动同步后，离开 Agent 页面、切换会话或关闭助手时按新增问答形成同步批次，提取与检索由 RAGFlow Native Memory 执行。记忆内容可能有误，不能替代当前业务数据。

上下文占用表示主 Agent 最近一次请求的输入，不等于会话累计消耗或费用；模型限额未知时显示未知。账本和额度能力另见Token 交付。

深入阅读：长期记忆交付、上下文统计、Agent 架构。
