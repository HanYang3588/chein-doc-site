Chein · 本体驱动的 Agent 平台

Chein 将业务本体、可追溯推理、知识检索、数据分析与多模态交互接入同一工作台。用户可以用自然语言查资料、分析业务数据、生成图片或视频，也可以通过本体与规则查看结论依赖的事实和判断过程。

核心特点：本体提供业务语义，决策模型选择执行路径，Agent 组织工具与交互，业务系统保留数据和权限。 RAG 与数据分析已有企业应用经验；本页截图来自测试环境，展示当前界面与实际操作结果。

系统架构全貌​

统一前端连接模块化管理平台与独立 Agent 运行时，集成本体推理、知识与记忆、媒体生成和配置服务；身份、授权、数据隔离与执行审计贯穿各层。

本体建模与可追溯推理​

通过 OWL 可视化构建器维护业务类、属性、关系与实例，支持数据目录导入、草稿恢复、校验和版本发布。HermiT 处理 OWL 一致性与逻辑推理；Neo4j 提供授权图读取、投影与多跳关系查询。

Logic Pack 将业务条件组织为规则、状态与目标，基于授权事实快照返回 TRUE / FALSE / UNKNOWN，附带证明树与重放结果。证据不足保留 UNKNOWN，业务操作仍由所属系统校验并执行。

图：在画布中组织业务概念、字段与关系，进入校验和发布流程。查看原图。

例如销售出库审核：定义本体 → 绑定授权事实 → 推导条件与证明 → Agent 解释 → ERP 人工审核。详见本体与业务结合。

Agent 编排与决策模型​

Deep Agents + LangGraph 负责模型与工具协作，PostgreSQL 检查点保留执行状态，AG-UI / SSE + assistant-ui 展示流式文本、工具事件、结构化结果和审批交互，支持长任务暂停、恢复与取消。

独立接入 System One 决策模型（decision-model-preview），在已授权范围内识别意图、筛选工具、路由知识库，并判断简单问题的检索证据是否充分。高置信度时收敛候选，低置信度或复杂任务交由主模型处理，减少无关能力干扰。

Nacos 配置、提示词与工具管理​

  • Agent 配置：Nacos 集中管理模型、决策、记忆、多模态等运行参数；运行配置在进程启动时加载。
  • Prompt 管理：支持系统与个人提示词、业务场景、适用范围、优先级和启停。正文草稿与发布版本由 Nacos 原生 Prompt 管理，新对话读取已发布的 latest，无需为提示词更新重启 Agent。
  • MCP 工具目录：按固定服务版本读取工具，核对 Schema、启用状态与权限；工具撤销或契约变化不能被旧会话绕过。

RAG 知识管理与数据分析​

RAGFlow 知识管理覆盖个人、团队与系统知识库，支持上传、解析、分块预览、共享授权和 Agent 绑定。检索结合关键词与向量召回、重排配置、元数据过滤及证据判断，回答附带原文引用与来源链接。

自然语言数据分析将指标、时间范围与分组转换为受控只读查询，展示图表并保存快照和收藏。数据源页面提供连接测试、库表字段目录、结构变化与脱敏配置，供分析和本体建模使用。

多模态：图片、视频与实时语音​

  • 图片生成：在对话中描述画面，调整尺寸与智能改写选项，直接查看图片、工具记录和结果说明；创作中心管理有权访问的图片资产。
  • 视频生成：以异步任务提交，独立 Worker 跟踪状态并管理结果；切换页面后仍可查询任务与资产。
  • 实时语音：接入 Qwen Realtime，通过 WebSocket 与 assistant-ui 语音适配器交互，提供转写、静音、打断和挂断；语音与文字共用会话和执行状态。

长期记忆与定时自动化​

RAGFlow Native Memory 保留原始对话并提取语义、情景与程序性记忆，支持跨会话检索、个人管理与遗忘。开启自动同步后，离开对话时将新增问答归为同步批次，页面展示提取进度与来源。

自动化任务支持指令、触发时间、时区、运行模式和通知配置，由独立 Scheduler 执行，保留运行记录与结果。每次运行继续使用当前授权的工具和数据。

可观测、评测与企业权限​

Langfuse 追踪 Agent 调用链、模型与工具耗时、Token 和成本，通过评测集对比基线与候选方案，辅助 Prompt 和策略迭代。系统另有个人 / 部门 / 租户用量账本与额度策略；实际计量范围见Token 交付。

多租户与最小授权贯穿业务、知识、本体和工具调用。Backend 签发短期委托，Agent 验签后执行，数据所有者逐次复验权限；业务模块使用各自的事务与数据隔离，不把模型判断当作授权。

观测范围与接入见Langfuse 交付。

技术底座与项目状态​

层次主要技术
业务与会话前端React 19、TypeScript、Umi Max、Ant Design、assistant-ui、React Flow
后端与 AgentPython、FastAPI、Deep Agents、LangGraph、LangChain、MCP
本体与知识OWL、OWLAPI、HermiT、Neo4j、RDFLib、pySHACL、RAGFlow / Elasticsearch
数据与媒体PostgreSQL、Redis、RustFS / S3 兼容存储
