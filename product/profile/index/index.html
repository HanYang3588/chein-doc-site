企业项目​

企业 AI 知识库与异常处置 Agent​

2025.12 至今 · 西安纽扣软件科技有限公司

项目简介：面向广告中台的 AI 应用，建设 RAG 知识库统一管理系统文档与渠道接入文档，并引入 Agent 自动分析业务异常，将结论推送到飞书，减少人工排查和知识交接成本。本人负责从方案设计到前后端开发与上线的全流程

技术栈：LangGraph、LangChain、Elasticsearch、Spring Boot、Redis、Langfuse、React、飞书开放平台

主要工作：

  1. Agent 异常分析：针对数据异常、投放问题等场景，基于 LangGraph 编排 Agent，通过 Function Calling、MCP 调用查询数据、检索知识库等工具，自动定位问题并给出处置建议
  2. RAG 知识库：针对中台 6 个系统文档和 30+ 广告渠道接入文档分散、检索困难的问题，建设统一知识库，覆盖 2000+ 篇文档，支持自然语言检索和渠道接入查询
  3. 检索优化：采用文档切分、混合检索（BM25+向量）、RRF 融合和 Rerank 重排，结合 Query Rewrite 与元数据过滤，Hit@5 从 60% 提升到 85%
  4. 飞书集成：通过飞书开放平台将分析结论以卡片形式推送给相关负责人，支持告警触发、交互式追问，缩短问题响应时间从小时降至分钟
  5. 团队提效：沉淀并推广 Agent 全栈开发经验，推动团队采用单人全栈交付模式，相关任务人力投入减少 50%

个人项目​

Agent 管理平台​

2025.03 至今 · 个人项目

项目简介：独立设计并开发以业务本体为核心的 Agent 应用平台，通过 OWL 可视化建模、约束校验与逻辑推理，将业务实体、关系及规则组织为机器可理解的知识体系，为 Agent 提供可查询、可推理的业务依据，支持推理过程与结论来源追溯，提升复杂业务问答和辅助决策的可解释性；结合工作流编排、多模态生成及实时语音，实现从知识建模到智能交互的完整链路

技术栈：DeepAgents、LangChain、LangGraph、RAGFlow、MCP、Langfuse、Higress、JEV、HermiT、Neo4j、Elasticsearch、FastAPI、React、assistant-ui、Ant Design、UmiJS、RustFS、Nacos、WebSocket、OWL

主要工作：

  1. 本体与形式推理：用 Neo4j 构建本体和知识图谱，通过独立的 HermiT 推理服务进行 OWL 形式推理。建立推理结果校验与不确定性拒答机制，确保业务结论有据可依、来源可溯，提升严肃业务场景下辅助决策的可靠性
  2. Agent 编排：基于 Deep Agents 和 LangGraph 搭建独立的 Agent 服务，支持任务状态持久化与执行进度实时反馈，提供中断、恢复和取消能力，提升长流程任务的可控性与可靠性
  3. 工具调用与权限：通过 MCP 接入业务工具，为数据分析提供只读的 ERP 统计接口。写操作进入人工审批，中断后可以恢复。Backend 向 Agent 下发短期委托凭证，Agent 校验后才能访问数据，避免越权
  4. 文档检索：通过 RAGFlow 接入共享文档检索，为回答附加原文引用与来源链接，提升回答可信度，实现依据可核验、来源可追溯。同时结合原生 Memory，支持语义、情景和程序性记忆的自动提取
  5. 评测与可观测：接入 Langfuse 追踪调用链路和 Token 成本，用 baseline 和 candidate 两组用例做对比评测，指导 Prompt 和策略迭代。另有检索评测集和记忆评测集
  6. 多模态与记忆：集成实时语音对话、图片与视频生成，支持异步生成任务管理、跨会话长期记忆及定时自动化执行，拓展 Agent 的交互方式与任务处理能力
  7. 全栈与工程化：前端使用 React 19、Umi、Ant Design 和 assistant-ui，实现流式对话、工具调用展示和审批界面。使用 Docker Compose 和 Nacos 管理部署与配置

实现补充：使用 PostgreSQL 保存 checkpoint，通过 AG-UI 协议（SSE）流式输出执行事件；基于 Qwen 与 WebSocket 实现实时语音对话，并按 assistant-ui 接口实现自定义语音适配器。视频生成和长期记忆同步由异步 Worker 处理

RPC 框架​

2024.11 至 2025.03 · 个人项目

项目简介：基于 Java、Vert.x 与自定义协议实现 RPC 框架。通过 Spring Boot Starter、注解和配置文件接入，使远程服务能够像本地方法一样调用；支持通过 SPI 扩展序列化器、负载均衡器、重试与容错策略

主要工作：

  • 实现消费方调用、序列化器、网络服务器、请求处理器与服务注册器等模块
  • 基于 Vert.x HTTP 服务器，完成服务提供者和消费者之间的网络通信
  • 使用线程安全的 ConcurrentHashMap 保存本地服务注册信息，按服务名取得实现类，并通过反射完成方法调用
  • 定义通用序列化器接口，基于 Java 原生 Object 和 ByteArray 输入输出流实现 JdkSerializer，使对象能够在网络传输
  • 基于 Vert.x Handler 异步处理请求，完成反序列化、服务定位和反射调用
  • 结合 JDK 动态代理与工厂模式，为指定服务接口生成能够发送 HTTP 请求的代理对象，实现远程方法的无感知调用
