Chein Agent 运行时

这是 Chein Agent 可独立部署的执行平面，不导入 backend/app，仅接受管理后端签发的短期委托上下文。

P0 范围​

  • 为已鉴权的 FastAPI Agent UI BFF 提供 AG-UI 流式端点。
  • 通过 Nacos 配置，直接流式调用 Qwen 兼容模式。
  • Platform 无法读取适用的 Nacos 提示词时，提供中文兜底系统提示词。Platform 在每次运行前解析租户、角色、岗位、用户和场景提示词；Agent 不存储提示词正文。
  • 验证签名委托上下文，并提供不依赖框架的 AgentStateV1。

当前工具集包括只读 ERP 统计，以及可选的 RAGFlow 检索，仅检索明确批准的共享文档。文件系统、Shell、任意网络访问和未经审核的写入工具仍保持禁用。

新增外部工具默认通过 Deep Agents interrupt_on 暂停执行，除非已明确审核为只读。BFF 提供已鉴权的审批、恢复和安全检查点重放端点。现有 assistant-ui ToolFallback 显示允许/拒绝控件、可选的文字拒绝原因，或供内置 ask_user 工具使用的文字回答。当前尚无业务写入工具；启用此类工具还需要业务授权、幂等键和操作效果审计。

本地运行​

个人自动化任务通过独立调度器复用同一 Agent 执行核心。使用 chein-agent-migration.yaml 执行 scripts/migrate_automations.py，然后运行 NACOS_CONFIG_DATA_ID=chein-agent-runtime.yaml uv run python -m chein_agent.automations.scheduler。 调度器需要 AUTOMATION_BACKEND_URL，以及与 Backend 相同的私有 AUTOMATION_SERVICE_TOKEN。不要在 Web 生命周期中启动调度器。参见自动化设计与部署。

在 Nacos 中创建 chein-agent-runtime.yaml，然后运行：

cd agent
NACOS_CONFIG_DATA_ID=chein-agent-runtime.yaml uv run fastapi dev src/chein_agent/main.py --port 8100

也可在仓库根目录运行 pnpm agent:dev，执行同一命令。

启动 API 前，先执行一次迁移，初始化持久化 PostgreSQL 检查点存储：

cd agent
NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/migrate_checkpoints.py
NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/migrate_projects.py

项目迁移命令也会应用 0004_project_icons：回填文件夹图标、校验支持的图标，并保留现有项目成员关系。部署支持图标的 API 前，先运行该迁移；回滚说明见 Agent UI。

运行时账户的访问范围仅限专用 agent Schema。迁移账户创建 LangGraph 检查点表，以及 Agent 拥有的 Thread、Run 和 RunEvent 控制面表；API 不会创建这些表。迁移完成后，为运行时角色授予 agent Schema 的 USAGE 权限，以及其中各表的 SELECT、INSERT、UPDATE、DELETE 权限。 部署此变更前，请重新运行迁移：它会在 Run 状态约束中增加 waiting_approval 和 waiting_input，并新增 approval_checkpoint_id 和 resume_decisions 列。Agent API 仍在请求内执行 Run；响应连接断开时，已批准的决策仍保留在 PostgreSQL 队列中，界面可恢复同一个 Run。当前未部署独立 Worker 或 MQ 消费者。

首批数据工具仅限当前日期/时间，以及 Backend 的签名 ERP 统计门面。在 chein-agent-runtime.yaml 中配置 AGENT_ERP_STATISTICS_URL、AGENT_DEFAULT_TIMEZONE 和租约边界；绝不要向 Agent 运行时提供 ERP 数据库 URL 或凭据。参见第 1 阶段交付。

知识检索使用 Backend Knowledge v2 门面。配置 AGENT_KNOWLEDGE_URL（现有 /internal/agent/v1 URL 会规范化为 v2）。签名上下文必须包含 agent:chat 和 knowledge:read。知识目录、绑定、ACL 和检索配置归管理模块所有；用户上传或共享文档时，不编辑 Nacos 中的静态数据集/文档列表。官方 RAGFlow SDK 仅保留为只读兼容代码，不作为新查询的回退路径。参见知识平台交付。

浏览器仅通过管理后端的 /api/v1/agent-ui BFF 访问 Agent；当前未部署 Node 协议适配器。

SQL 分析与 ERP 统计使用同一套已审核的后端 MCP 服务。AGENT_MCP_SERVERS 选择其固定版本；MCP 模式无需 AGENT_ANALYTICS_URL。Agent 包装器防止完整数据行进入模型上下文，并生成已授权的图表快照。HTTP 配置仅在 MCP 列表为空时用于滚动迁移；MCP 出错时绝不回退到 HTTP。发布顺序、权限和兼容性见 SQL 分析交付。

可选的 Langfuse 元数据追踪、业务阶段、持久化反馈、有界查询和离线评测已实现，默认关闭。先应用 Agent/Platform 增量迁移，配置 Agent 和可选的 Backend OTLP 设置，授予角色权限，再重启 Worker；参见 Langfuse P1–P5 交付与配置。早期的 LangSmith 设计仍未实现。这两项服务均不拥有业务 Run/检查点状态。

可选的决策模型路由使用阿里云独立的 System One API，通过 AGENT_DECISION_MODE=off|shadow|active 配置，默认关闭。先在 Nacos 中启用 shadow，并重启 Agent 进行评测。能力路由、回退及独立的 Higress 端点/路径/密钥配置见决策模型集成。

视频 Provider 与 generate_video 的边界、Token Plan 配置和独立 Creation Worker 启动方式见 视频生成设计。Agent 工具只返回持久化 job ID，不等待最终视频。

可选的长期记忆​

RAGFlow Native Memory 是唯一的长期记忆引擎。本运行时拥有私有 HTTP 适配器、租户/所有者到空间的映射、用户同意状态和持久化投递元数据。RAGFlow 拥有原始、语义、情景和程序性内容，并负责提取与检索。现有视频 Worker 调度私有 HTTP 周期调用，无需额外 Worker。检查点历史、压缩和审批恢复保持独立。

Memory 默认关闭，需由所有者主动开启。提交状态不明时，不盲目重试。参见设计和迁移与交付指南。

可选的 Token 计费与预算​

设置 AGENT_TOKEN_BUDGET_MODE=observe 前，先使用迁移凭据执行 NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/migrate_token_billing.py。 通过以下命令启动独立汇总 Worker： NACOS_CONFIG_DATA_ID=chein-agent-runtime.yaml uv run python -m chein_agent.usage.aggregator。 Worker 会取得 PostgreSQL 领导者锁，不在 Web 生命周期中启动。 默认模式为 off。迁移会应用 0012 和增量迁移 0013。先使用 observe；通过运维验收后，再以 enforce 启用分层硬预算。价格采用经审核、仅追加的版本，不自动下载或编造。网关和持久化收件箱通知分别通过独立开关启用。当前仍无法获取 RAGFlow 内部用量；硬预算下的 Memory 推理/提交采用失败关闭策略。 参见交付与剩余门禁。
