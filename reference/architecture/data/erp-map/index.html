ERP 数据地图：表、字段与"该查哪张表"

状态：操作与事实说明（表结构以 backend/app/modules/erp/infrastructure/models.py 为准）。

适用范围：schema erp 下的业务与分析审计表；当前 ModuleDefinition 声明 41 张表。erp_analytics 是受保护的只读分析视图 schema，不属于普通 API 账号的通用查询入口。

所有表都在 PostgreSQL schema erp，都带 tenant_id。查询前先读 总览 的 "查询数据前必须知道的四件事"，尤其是租户/RLS 与 owner、仓库授权三层可见性。

1. 表分组总览​

分组表
主数据product_unit、product_category、product、warehouse、warehouse_user_grant、supplier、customer、settlement_account
采购purchase_order / purchase_order_item、purchase_in / purchase_in_item、purchase_return / purchase_return_item
销售sale_order / sale_order_item、sale_out / sale_out_item、sale_return / sale_return_item
库存单据stock_in / stock_in_item、stock_out / stock_out_item、stock_move / stock_move_item、stock_check / stock_check_item
库存事实stock_balance（余额）、stock_ledger（流水，只追加）
财务finance_payment / finance_payment_item、finance_receipt / finance_receipt_item
平台支撑document_sequence、document_action_log、command_receipt、document_attachment、erp_setting、reconciliation_run、analytics_query_audit

2. 主数据表​

表关键列什么时候查它
product_unitcode、name、symbol、is_active换算单位、显示单位名
product_categorycode、name、parent_id、sort、is_active分类树、按分类统计
productcode、name、category_id、unit_id、barcode、specification、weight、expiry_days、purchase_reference_price、sale_reference_price、min_sale_price、is_active商品档案、参考价与最低售价（销售校验用它）
warehousecode、name、contact_name、contact_phone、address、storage_fee_reference、transport_fee_reference、is_active、is_default仓库列表、默认仓库、仓储/运输参考费（每个租户最多一个 is_default）
warehouse_user_grantwarehouse_id、user_id、granted_by、granted_at判断某人能看哪些仓库（唯一键 tenant_id + warehouse_id + user_id）
suppliername、contact_name、mobile、phone、email、tax_no、tax_rate、bank_name、bank_account_encrypted、bank_account_last4、is_active采购往来单位；银行账号是密文，明文只在敏感接口返回
customer同 supplier 字段结构销售往来单位
settlement_accountname、account_no_encrypted、account_no_fingerprint、account_no_last4、is_default、is_active收付款账户；account_no_fingerprint 用于唯一性校验，每个租户最多一个默认账户

注意：supplier / customer 以 name 在租户内唯一，没有单独的 code 字段。

3. 业务单据表（含状态与数量回写列）​

表单号前缀关键回写列说明
purchase_order / _itemCGDDitem.received_quantity、item.returned_quantity采购订单；明细单价 unit_price，含 discount_rate / deposit_amount
purchase_in / _itemCGRK表头 settled_amount；明细 returned_quantity采购入库；明细必须挂在某个采购订单行上
purchase_return / _itemCGTH表头 settled_amount采购退货；明细回指 purchase_in_item_id 与 purchase_order_item_id
sale_order / _itemXSDDitem.shipped_quantity、item.returned_quantity销售订单；建单时校验 unit_price >= product.min_sale_price
sale_out / _itemXSCK表头 settled_amount；明细 returned_quantity销售出库；明细回指 sale_order_item_id
sale_return / _itemXSTH表头 settled_amount销售退货；明细回指 sale_out_item_id 与 sale_order_item_id
stock_in / _itemQTRK-其他入库，可挂 supplier_id
stock_out / _itemQTCK-其他出库，可挂 customer_id
stock_move / _itemKCDB-调拨，明细含 from_warehouse_id、to_warehouse_id，两者必须不同
stock_check / _itemKCPD-盘点，明细含 snapshot_quantity、actual_quantity、difference_quantity（数据库约束 difference = actual - snapshot）

共同列：no、status、version、business_at、owner_id、total_quantity、 total_amount、审批与反向操作人/时间列（见 总览 第 4 节）。 明细统一有 line_no、product_id、product_name、unit_name、quantity、 reference_price、tax_rate、product_amount、tax_amount、total_amount、remark。

金额口径差异（容易问错）：

  • purchase_order：total_amount = product_amount + tax_amount - discount_amount （字段里有 deposit_amount 定金，但不参与该公式）。
  • purchase_in / sale_out / purchase_return：total_amount 含 other_fee 或 other_deduction（入库加其他费用，出库减其他扣款）。
  • sale_return：total_amount 含 other_deduction。

4. 库存事实表​

表含义关键列
stock_balance当前余额（每个商品 × 仓库一行）product_id、warehouse_id、quantity、version、updated_at
stock_ledger只追加的出入库流水delta_quantity、balance_after、ledger_type、source_document_type、source_document_id、source_item_id、source_document_no、source_version、reversal_of_id、operator_id、occurred_at

不变式：stock_balance.quantity = SUM(stock_ledger.delta_quantity)（按商品+仓库），且 quantity >= 0。 详见 04-库存管理.md。

5. 财务与平台支撑表​

表关键列用途
finance_payment / _item表头 supplier_id、settlement_account_id、total_settlement_amount、discount_amount、payment_amount；明细 source_type、source_document_id、source_total_signed、settled_before_signed、settlement_signed、discount_allocated付款单（FKD）核销采购入库/退货
finance_receipt / _item结构与付款单对应，往来方为客户收款单（SKD）核销销售出库/退货
document_sequence主键 (tenant_id, prefix, sequence_date)、next_value单号按天递增，跨天自动从 1 重新开始
document_action_logresource_type、resource_id、resource_no、action、old_status/new_status、old_version/new_version、actor_id、reason、metadata_json、occurred_at审批/反向/导出/敏感字段查看的审计轨迹（只追加）
command_receiptcommand_name、idempotency_key_sha256、request_sha256、resource_type、resource_id、resource_version、status（processing/completed）、expires_at写命令幂等凭证；过期后由计划任务清理
document_attachmentdocument_type、document_id、file_id、sort、created_by单据附件关联（真实文件在平台文件模块）
erp_setting主键 tenant_id、timezone、integrity_status（healthy/degraded）、last_reconciled_at、version租户级 ERP 设置与对账健康状态
reconciliation_runstatus（running/passed/failed）、stock_difference_count、settlement_difference_count、summary_json、started_at、completed_at、triggered_by每次对账的结果快照

6. 按业务问题选表（常用查询）​

以下 SQL 都假设已选定租户，<tenant> 等为占位符。

某商品在所有仓库的当前库存

SELECT w.name AS warehouse, b.quantity, b.updated_at
FROM erp.stock_balance b
JOIN erp.warehouse w ON w.id = b.warehouse_id AND w.tenant_id = b.tenant_id
WHERE b.tenant_id = '<tenant>' AND b.product_id = '<product>'
ORDER BY w.name;

某商品 + 仓库的库存是怎么变成现在这样的（流水）

SELECT occurred_at, ledger_type, delta_quantity, balance_after,
       source_document_type, source_document_no, source_version
FROM erp.stock_ledger
WHERE tenant_id = '<tenant>' AND product_id = '<product>' AND warehouse_id = '<warehouse>'
ORDER BY occurred_at, id;

某采购订单的执行进度（订了多少、收了多少、退了多少）

SELECT i.line_no, i.product_name, i.quantity, i.received_quantity, i.returned_quantity,
       (i.quantity - i.received_quantity) AS outstanding
FROM erp.purchase_order_item i
JOIN erp.purchase_order o ON o.id = i.purchase_order_id AND o.tenant_id = i.tenant_id
WHERE i.tenant_id = '<tenant>' AND o.no = '<采购订单号>'
ORDER BY i.line_no;

某供应商的采购入库金额（排除已反向的单据）

SELECT date_trunc('month', business_at) AS month, SUM(total_amount) AS amount
FROM erp.purchase_in
WHERE tenant_id = '<tenant>' AND supplier_id = '<supplier>'
  AND status = 'approved'
  AND business_at >= '<from>' AND business_at < '<to>'
GROUP BY 1 ORDER BY 1;

某客户销售出库 / 退货净额

SELECT 'out' AS kind, SUM(total_amount) FROM erp.sale_out
WHERE tenant_id = '<tenant>' AND customer_id = '<customer>' AND status = 'approved'
  AND business_at >= '<from>' AND business_at < '<to>'
UNION ALL
SELECT 'return', -SUM(total_amount) FROM erp.sale_return
WHERE tenant_id = '<tenant>' AND customer_id = '<customer>' AND status = 'approved'
  AND business_at >= '<from>' AND business_at < '<to>';

某张入库单还剩多少没结算

SELECT no, total_amount, settled_amount, (total_amount - settled_amount) AS outstanding
FROM erp.purchase_in
WHERE tenant_id = '<tenant>' AND status = 'approved' AND no = '<入库单号>';

某张入库单被哪些付款单核销过

SELECT p.no AS payment_no, p.status, p.business_at,
       item.settlement_signed, item.discount_allocated
FROM erp.finance_payment_item item
JOIN erp.finance_payment p ON p.id = item.finance_payment_id AND p.tenant_id = item.tenant_id
WHERE item.tenant_id = '<tenant>'
  AND item.source_type = 'purchase_in'
  AND item.source_document_id = '<purchase_in_id>'
ORDER BY p.business_at;

某单据的审批/反向/导出历史

SELECT occurred_at, action, old_status, new_status, old_version, new_version, actor_id, reason
FROM erp.document_action_log
WHERE tenant_id = '<tenant>' AND resource_type = 'purchase_in' AND resource_id = '<document_id>'
ORDER BY occurred_at;

最近一次对账结果与租户健康状态

SELECT r.status, r.stock_difference_count, r.settlement_difference_count,
       r.started_at, r.completed_at, r.summary_json,
       s.integrity_status, s.last_reconciled_at
FROM erp.reconciliation_run r
LEFT JOIN erp.erp_setting s ON s.tenant_id = r.tenant_id
WHERE r.tenant_id = '<tenant>'
ORDER BY r.started_at DESC LIMIT 1;

某租户的仓库授权（谁能看哪个仓库）

SELECT g.warehouse_id, w.name, g.user_id, g.granted_at
FROM erp.warehouse_user_grant g
JOIN erp.warehouse w ON w.id = g.warehouse_id AND w.tenant_id = g.tenant_id
WHERE g.tenant_id = '<tenant>';
