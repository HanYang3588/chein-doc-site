对话本体与决策控制

状态：2026-10-28 工作区实现及本地验证；不是生产部署记录。运行边界继续以Agent 架构为准。

使用方式​

完整对话页与浮动对话共用输入框旁的“本体与决策”入口。面板只展示本体与决策模型两个开关，默认均开启；移除弹层顶部“本体与决策 / 恢复默认”行。控件后的圆圈感叹号可点击展开说明，支持键盘与 Escape 收起。设置作用于下一次新 Run；运行中、等待审批或等待恢复时锁定。切换会话或新建会话恢复默认，恢复已有 Run 时从服务端绑定记录恢复设置。

控件含义
业务本体默认开启并请求 Neo4j 来源全部已授权本体工具与推理；手动关闭发送 ontologyProvider=off，重新开启恢复 neo4j、全部获准工具及推理
决策模型开启表示沿用服务端 Qwen off/shadow/active 配置；关闭则阻止当前 Run 的决策模型请求，不切换生成模型

两个开关表示使用偏好。能力仍在加载、目录为空、读取失败或服务未就绪时，保持用户原选择，不自动变成关闭，用户仍可手动切换；能力说明收在控件后的图标中。运行中、等待审批或等待恢复的既有锁定规则保留。开启不会发布工具、启用服务或授予权限，实际调用仍通过已审核目录、部署开关和当前授权校验。没有决策服务时开关仍表示“允许使用”的偏好，服务端仍沿用原普通流程，不能把界面开启解释为服务已实际启用。开启表示允许使用，不证明本轮一定调用；实际使用仍看工具事件和既有决策记录。比较效果建议使用不同新对话与相同问题，避免已读本体或历史答案影响后续结果。

契约与执行​

同源 BFF /api/v1/agent-ui 的聊天、编辑、重跑、审批和恢复输入兼容扩展可选 executionOptions：

{
  "ontologyProvider": "neo4j",
  "ontologyTools": null,
  "ontologyInference": true,
  "decisionModel": true
}

Provider 固定为 default/off/legacy/neo4j；工具仅允许已声明的十个固定本体工具，最多十项；两个开关为严格布尔。未携带设置的旧 API 客户端仍缺省为 default/null/true/true；新页面显式发送 neo4j/null/true/true。空工具数组表示不提供本体工具；关闭推理优先于工具列表中包含 semantic。

上述细粒度字段保留为既有客户端及历史 Run 的兼容契约。简化后的页面只提供 neo4j/off 开关，并将 ontologyTools 恢复为 null、ontologyInference 恢复为 true；本轮工具仍取已授权交集。恢复旧 Run 不改写原绑定值。

GET /api/v1/agent-ui/execution-options 经过当前登录和授权，将请求代理到 Agent 的只读能力接口；Neo4j/本体部署标志由 Backend 计算，浏览器不能自行改变。响应只含固定工具名、当前就绪来源、决策模式及固定不可用原因，不返回端点或密钥。就绪来源用于说明，不作为保存来源偏好的前提；目录不可用时仍能手动开关本体偏好。

Agent 在加载 MCP 前，按现有 Run lease 和 tenant/owner 验证，将设置写入 execution.options.bound RunEvent；恢复/审批优先返回原绑定值。没有绑定记录的旧恢复 Run 使用旧默认设置。没有新增表或迁移，也不改变 MCP 版本绑定、checkpoint、取消或审批协议。agent.execution_options custom 事件回显服务端实际采用的设置，页面据此恢复选择。

工具只在既有审核目录与当前 delegation 的交集内缩减；逐次调用仍重验目录撤销及源权限。Agent 通过固定 x-chein-ontology-provider 传输头传递来源偏好，模型输入 Schema 不提供该字段。Backend 在验证签名 delegation 后仅接受固定枚举，通过 ContextVar 隔离请求；Ontology 继续复验模块、成员、发布版本、摘要、来源和数据权限。该枚举不是租户/用户身份，不授予额外权限。普通 Studio HTTP 调用保留原部署策略。

决策开关使用 Run ContextVar：入口路由、Knowledge 库选择与证据判断、本体风险提示等在当前执行作用域内使用有效模式，底层 decide() 在关闭时也拒绝外呼。缺配置、连接失败、超时或无效结果继续原有普通 Agent/结构化知识判断 fallback。Knowledge ACL、ERP 业务校验、Memory 治理的证据门禁均保留；后台任务及其他对话没有继承本轮偏好。离线评测 Judge 和没有传入对话设置的独立入口仍沿用各自既有配置。

主要实现​

  • backend/app/platform/agent_ui_router.py：输入契约、能力 BFF 与续答转发。
  • backend/app/modules/agent_tools.py、ontology/application/providers.py：验证后读取固定来源枚举、并发隔离及部署关闭检查。
  • agent/src/chein_agent/execution_options.py：严格偏好、有效决策模式及无外呼可用性判断。
  • agent/src/chein_agent/runs.py、api.py：RunEvent 绑定、恢复、设置事件和实际执行作用域。
  • agent/src/chein_agent/mcp_tools.py：审核后过滤工具、冻结传输头；既有撤销复验保留。
  • decision.py、decision_middleware.py、knowledge_pipeline.py、ontology.py：关闭与默认 fallback。
  • frontend/.../modules/platform/agent/ExecutionControls.tsx：共享可访问面板；pages/agent 负责发送与恢复设置，类型来自生成客户端。

本地验证​

分批执行，不相加为互不重叠总数：

  • Agent 在 NACOS_ENABLED=false、无正常决策配置的进程中：169 passed、2 skipped；包含对话/API、决策、Knowledge、MCP、语音与自动化兼容、Memory 治理和新偏好测试。两个 skip 为已有显式外部数据库门禁。
  • Backend 通过 test_creation_isolated.py 创建并清理一次性 PostgreSQL：73 passed；包含 BFF、签名 delegation、MCP 组合根、Provider 并发隔离及模块边界。未对正常业务库运行 db fixture。
  • 真实一次性数据库的 app_runtime 角色下，Run 设置首次绑定、重复调用、恢复保留及跨 tenant/owner/worker/lease 拒绝：1 passed。
  • 新面板及事件校验：5 passed；原 Agent 对话页：75 passed。Ruff、前端类型检查、API 生成及 base/items/suite 构建通过。
  • 浏览器使用真实构建、BFF、独立 Agent、受限 PostgreSQL 和正常 Qwen 生成模型，关闭本体、关闭且未配置决策服务后仍成功回答“对照开关测试成功”；数据库核实 Run succeeded 和绑定来源 off。decisionModel=true 在该环境表示继承服务端 off，不记为启用决策模型。
  • 隔离工具目录下，页面选择 Legacy、仅允许发现本体、关闭类继承推理和决策辅助；真实 Qwen 只调用 ontology_search_v1 并成功。工具响应为 provider=legacy、requested_provider=legacy、fallback_used=false；绑定记录为 decisionModel=false、ontologyInference=false。原始工具列表仍可包含 semantic，但关闭推理后的有效交集排除它。
  • 隔离 Agent 将决策端点设为本机未监听端口，保持普通 Qwen 配置：新对话实际记录 mode=active、status=fallback、reason=provider_unavailable，页面显示“决策回退 · 继续由主模型处理”并正常回答，Run succeeded。故障注入仅作用于临时进程。

部署与剩余门禁​

2026-10-25 面板简化后重新验证：5 项控件/事件测试及 75 项对话页测试通过，前端类型检查和构建通过。浏览器使用实际组件和生产 CSS、隔离的能力响应检查下拉、开关、标题说明与 Escape；不是新一轮真实 MCP/模型端到端验收。最新截图为 agent-ui/screenshots/2026-10-25/98efac6655d74451a50c23c4c6aef3d6/chat-controls-simplified.png，已归档 RustFS；前述细粒度面板截图仅为简化前的历史验证。

来源禁用回归修复：原实现将来源偏好与目录就绪状态绑定，空目录导致两个选项都禁用。已移除该绑定，保留后端执行门禁；6 项控件/事件测试与 75 项对话页测试（共 81 项）、类型检查和前端构建通过，覆盖加载中、空目录和目录读取失败。浏览器以真实组件、生产 CSS 和空目录响应验证自建/Neo4j 两次切换，并检查所选来源的未就绪说明。截图 agent-ui/screenshots/2026-10-25/9d43c774b2b4483a83e54a3759d4d133/ontology-source-selection-fixed.png 已归档 RustFS。2026-10-26 收尾核对实现与证据；本次回归修复只需更新前端，无新增配置或数据库迁移，也不要求重启 Backend/Agent。正常 MCP 新版本发布及其真实本体调用仍待单独验收。

完整功能无需新增配置项、依赖或数据库迁移。部署完整功能时更新 Backend、Agent 与前端；沿用已有模型和 Neo4j 连接。本体工具是否能实际执行仍取决于已审核目录、权限和部署开关，页面不会替代 MCP 发布流程。关闭决策辅助不需要删除密钥或修改 Nacos，恢复默认也不创建新的服务。

远端 CI、生产部署、正常目录新版本发布、生产权限角色验收、生产负载与 N-1 演练未执行；既有供应链审计问题见双工作区交付。

2026-10-28 默认开启的双开关​

前端将本体来源下拉替换为 Neo4j 本体使用开关，删除弹层标题与恢复默认整行。新会话显式默认 ontologyProvider=neo4j、ontologyTools=null、ontologyInference=true、decisionModel=true；手动关闭分别发送 off / false。能力查询仅用于说明，不因加载、失败、空目录或服务未配置自动关闭或禁止手动切换。弹层开关关闭/重开保留选择；新建、切换会话沿用已有默认初始化，旧 Run 的恢复/审批仍沿用历史绑定值。

本地相关回归 91 passed（共享面板 8 项、主对话/浮动助手 83 项），覆盖两处实际发送的默认与手动关闭参数。TypeScript 类型检查通过。Playwright 在主对话页的真实构建、临时静态服务及全模拟 API 中验证 1280px 和 375px 两个视口：两个开关默认开启，标题/恢复默认行和下拉消失，手动开关及 Escape 收起正常，面板未横向溢出，无 pageerror。没有操作真实 Agent/模型或业务数据库。

首轮全量前端测试 343 passed / 3 failed，失败均为未修改的 Favorites 图表用例；单独复跑该文件 5 passed。最终串行复跑全量 42 files / 346 tests 全部通过，前端类型检查、构建及 git diff --check 通过。不改后端/Agent 契约、Nacos 配置、运行时默认或授权逻辑，无新增依赖、迁移及生成客户端变更；只需更新前端。真实 MCP/模型联调、远端 CI 和生产部署未执行。

间距微调：本体开关文案改为“业务本体”，弹层按内容收紧，移除两行之间的分隔线；相关 91 项回归、类型检查及构建通过。模拟 API 浏览器验证在 1280px / 375px 下弹层宽 164px，文字组与开关间距 12px，无分隔线、溢出或 pageerror。
