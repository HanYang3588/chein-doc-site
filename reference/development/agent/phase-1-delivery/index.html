Agent Phase 1 运行控制与只读数据工具

状态：Implemented slice（以代码、迁移和测试为准）

（仅同步 React 工具渲染入口）

本文只描述当前已交付的最小 Phase 1 竖切，不替代 Agent 架构 和本目录的目标态设计。

1. 范围​

本次交付把一个聊天请求纳入 Agent 自己的 PostgreSQL 控制面，并增加两个 显式注册、无副作用的工具：

Tool作用数据边界
get_current_date返回配置时区的当前日期和时间不访问数据库或网络
get_erp_statistics读取 ERP 已批准单据的汇总或时间序列只调用 Backend 内部 ERP Statistics Facade；不接收 SQL、表名、连接串或 tenant_id

此阶段未交付 RAGFlow；当前已另行加入共享文档只读检索，范围见 技术栈与外部集成。Agent 仍不具备写 ERP、文件、Shell、 任意 HTTP、代码执行或产物上传能力。它不导入 backend/app，也不直接连接 ERP schema。

2. 数据与授权路径​

浏览器 JWT
  -> Backend Agent UI BFF（agent:chat）
  -> 计算 erp:statistics:query 是否实际拥有
  -> 带 scopes、tenant、user、run、thread 的短期签名委托上下文
  -> Agent 工具
  -> Backend 内部 ERP Statistics Facade
  -> Tenant UoW、RLS、所有者/仓库数据范围与现有统计口径

Facade 每次调用都验证签名、有效期、Run/Thread 绑定和 erp:statistics:query scope。scope 缺失、token 无效、ERP 模块不可用或数据 范围不允许时失败关闭。模型永远不会拿到平台 JWT、数据库连接串或任意 SQL 执行能力。

summary 复用 ERP 的 today/yesterday/month/year 口径；time_series 只接受 purchase/sale、ISO 日期和 day/month 粒度，最多 366 天。返回的是经 JSON 序列化的有限统计 DTO，不返回交易明细。

3. Run 控制面​

agent_runs 与 agent_run_events 属于 agent schema：

  • Run ID 由 Agent UI BFF 生成，同时作为租户和用户范围内的幂等键。
  • 当前新 Run 直接进入 running，并以 succeeded|failed|cancelled 结束； 敏感工具中断时进入 waiting_approval，决定提交后进入 queued 再恢复。重复请求只会获取已有 Run；正在处理的 同一 Run 不会再次执行模型。
  • 领取 Run 会写入 lease owner、epoch 和过期时间。只有当前 lease owner 才能 heartbeat 或写终态；过期 lease 可由下一次同 Run 请求领取。
  • POST /internal/agent/v1/runs/{run_id}/cancel 对运行中的 Run 记录取消请求， 对排队和待审批 Run 直接置为取消；流式循环在下一次模型消息前检查。 已发生的只读调用不会被伪装为撤销。
  • 控制面只保存状态、租约、错误码和小型事件元数据；Prompt、模型文本、凭据 与 ERP 原始行不进入 agent_run_events。
  • DeepAgents 的工具调用转换为 AG-UI 的开始、参数、结束与结果事件，供当前 React assistant-ui 工具部件渲染；RunEvent 只记录工具状态，不复制工具参数或结果。前端接线 与深度思考/图表边界见 Agent UI 设计，不沿用旧 Vben UI 的完成结论。

当前 API 进程内领取和执行 Run，适合单 Worker 本地/首期部署。手动恢复已批准 Run 与受限检查点重跑已实现；独立队列、 重试调度、Outbox、ArtifactStore、SSE cursor 重放与跨进程 worker reaper 仍是 后续 Phase 1/2 工作，不能据此宣称已经具备完整恢复能力。

4. 配置与迁移​

Nacos chein-agent-runtime.yaml 新增：

AGENT_DEFAULT_TIMEZONE: "Asia/Shanghai"
AGENT_ERP_STATISTICS_URL: "http://chein-backend.internal:8000/api/v1/erp/internal/agent/v1/statistics"
AGENT_ERP_STATISTICS_TIMEOUT_SECONDS: 10
AGENT_RUN_LEASE_SECONDS: 120

AGENT_ERP_STATISTICS_URL 是固定的内网 Facade URL，不是模型可控参数。运行 前仍需用 migration 凭据执行 agent/scripts/migrate_checkpoints.py；它创建 Agent-owned Run/event 表、将原型期全局主键升级为 (tenant_id, id) 联合主键， 并授予 runtime role 最小的 CRUD 权限。Backend 不需要 新增密钥：它使用已有 Agent delegation private key 签发 scope，Agent 使用 已有 public key 验证。

5. 验收与限制​

本地自动化测试覆盖：日期工具、统计工具参数限制与固定 HTTP 契约、预取消 Run 的 AG-UI 收尾与工具事件、Agent Harness 的工具注册与文件拒绝、Backend delegation scope 与 Facade 的拒绝路径。Run 幂等/lease 的真实 PostgreSQL 并发 演练、完整端到端测试仍依赖已配置 Nacos、PostgreSQL、ERP seed 数据与 Qwen， 不能以单元测试替代。

新增工具或扩展统计维度前，先更新本文、ToolDescriptor、后端 Facade 契约和 固定评测用例；不允许以 Prompt 或模型输出扩大数据范围。

当前尚未实现 Higress 模型响应或工具结果缓存；缓存作用域、失效和验收以 Agent 缓存与请求合并 为准。
