SQL 分析与图表收藏交付

2026-10-10：已实现设计中的 B/C/D/E 首期切片，并完成本地验证；尚未部署到实际环境。 运行时边界见 Agent 架构，需求与后续范围见 设计。

可用范围​

Suite 新增 Analytics 模块。Agent 的 get_analysis_catalog 和 analyze_data 包装现有 MCP 工具，经签名委托调用后端能力 Provider；入口决策仍使用已有 Qwen 配置。查询使用结构化 QuerySpec，规则编译与 SQLGlot 校验不增加决策模型调用，也不接受模型 SQL。

Analytics 在 ModuleDefinition.agent_tools 声明 analysis_catalog_v1、analyze_data_v1、analysis_scope_v1、analysis_cancel_v1，与 ERP 共用现有 /mcp 入口和 Nacos 固定版本目录。Agent 保留图表生成、快照和有界摘要，完整查询结果与技术用的 scope/cancel 工具不直接进入模型工具列表。每次 MCP 调用复验 Nacos 开关、契约及委托，数据所有者继续复验业务授权。原始分析响应最多 1 MiB，MCP 的文本/结构化双份封装最多 2 MiB；其他 MCP 工具仍限制 256,000 字节。

已发布两个数据集：采购入库及退货、销售出库及退货。只统计已审核单据，退货扣减净金额；入出库单数不是订单数。支持日期、单据类型、日/月粒度及指定指标排序。尚未发布供应商、商品或仓库排名，不能通过猜测字段查询它们。

查询逐次重验当前成员、权限、模块权益、owner 范围和仓库授权；包含未授权仓库的单据整单排除。SQL 执行后再次核对 scope。模型不能指定租户、账号、仓库授权、数据库地址或物理表。

前端统一渲染折线、柱状、条形、饼图和表格，适用于完整聊天、浮动助手和收藏页。混合单位、负值饼图、不适合绘图的结构和超出 JavaScript 安全精度的数值降级为精确表格。空结果和 NULL 单独展示。

图表右上角的三点菜单统一提供图表/数据表切换、按现有权限收藏和复制为图片。复制使用已安装的 html2canvas 1.4.1 与浏览器 Clipboard API，在本机生成当前显示内容的 PNG，包含卡片标题和时间范围，排除操作按钮；图表卡片及复制图片均不展示数据查询时间；表格只复制当前可见页及滚动区域，不代表导出全部查询结果。复制用的页面克隆兼容 Tailwind 主题颜色与聊天消息的 content-visibility；导出期间为 html2canvas 的隐藏字体测量标记恢复 inline 显示，避免标题裁切和分页文字下移，成功或失败后均移除该临时样式，不改变可见页面布局。浏览器须支持图片剪贴板并运行于 HTTPS 或 localhost；拒绝访问或渲染失败时仅提示错误，保留图表和收藏状态，无 API 或数据库迁移。

本轮已获准注册 get_analysis_catalog 与 analyze_data 时，Agent 在兜底或 Nacos 系统提示词后追加当前图表能力及使用说明；入口决策目录也说明获准的图表能力。趋势和图表请求优先走分析工具，追问“输出成折线图”沿用已确认的指标与时间范围重新查询并生成授权快照，明确这是本次查询。旧 ERP 统计工具只返回统计数据，不触发图表渲染。未注册分析工具、查询失败或结果不适合绘图时，仍需如实说明限制，不承诺已生成图表。此说明调整不改变后端 MCP 契约，无需重新发布版本。

个人收藏支持保存、查看、编辑、删除、手动刷新、打开时刷新一次和继续分析。收藏卡片不显示更新时间；原底部的查看、刷新、编辑、继续分析和删除合并到图表三点菜单，与图表/数据表切换和复制图片共用入口。菜单沿用操作权限和忙碌状态，删除保留确认；快照加载失败时仍提供收藏操作入口。查看弹窗也使用该菜单。收藏页使用响应式卡片网格，每页预览 6 张图表，直接读取已授权的历史快照；单张读取失败可独立重试。预览不触发重新查询，“打开时刷新一次”仍在点击“查看图表”时执行。继续分析只传收藏 ID；后端按当前身份解析定义，Agent 重新查询。刷新通过定义版本与刷新代次控制并发，失败不替换原快照。首期个人列表最多返回最近 200 条。

历史快照每次读取都复验源权限和 scope；历史消息与发给模型的旧分析上下文也会校验。过期、撤权或 scope 变化时不返回旧数值。撤权不主动擦除浏览器已经收到的数据，需要下一次读取或刷新触发复验。

数据所有权与预算​

内容所有者与边界
ERP 数据、分析视图、查询审计ERP；erp_analytics 由 ERP MigrationSpec 声明，API 运行账号不获得该 schema 的读权限
收藏定义Analytics 的 analytics.chart_favorite；Tenant UoW + owner RLS，超级用户也不能借个人接口读取别人的收藏
不可变快照Agent 的 agent.analysis_snapshot；tenant/user RLS，运行账号只有 SELECT/INSERT，校验内容 checksum
QuerySpec/ChartSpecV2纯 DTO app.modules.analysis_contracts；Agent JSON Schema 与前端客户端由仓库生成命令派生

最大时间范围 366 天、结果 500 行/512 KiB；超预算拒绝，不把截断结果当作完整统计。模型只收到有界摘要、最多 8 行样本和图表引用。快照保留 7 天，审计保留 30 天；快照去重键绑定 tenant/user/run/实际 tool call ID。

共享 Redis 限额为全局 8、租户 4、用户 1 个并发查询，用户每分钟 10 次、每 Run 3 次尝试。Redis 不可用时拒绝查询。租约 30 秒，执行总截止 8 秒，SQL statement timeout 最多 5 秒；取消通过绑定用户与 Run 的查询 ID 调用专用连接的 PostgreSQL cancel，不暴露 PID。

启用步骤​

下列命令用于有授权的目标环境。本轮仅在隔离的本地 PostgreSQL/Redis 执行，未修改已有应用数据库或 Nacos。

  1. 使用 Suite 交付，先备份并迁移管理后端，再更新普通运行账号的模块表授权：

    cd backend
    NACOS_CONFIG_DATA_ID=chein-backend-bootstrap.yaml uv run python -m app.modules.migrate --edition suite
    NACOS_CONFIG_DATA_ID=chein-backend-bootstrap.yaml uv run python -m app.platform.provision_db_roles

    已有安装还需要同步模块菜单及权限；数据库迁移不会创建菜单。使用现有初始化入口：

    APP_EDITION=suite NACOS_CONFIG_DATA_ID=chein-backend-bootstrap.yaml uv run python -m app.initial_data

    该命令可重复执行，从模块声明创建 Analytics 菜单和 analytics:* 权限，并为默认租户内置角色补充菜单绑定、刷新权限缓存；同时播种平台其他基础数据。它不会自动启用 Analytics 模块权益，也不会把已有普通用户提升为平台超级管理员。其他租户或自定义角色仍由管理员明确授权。

  2. 在私有 bootstrap Data ID 配置 ANALYTICS_DB_PASSWORD，显式创建专用分析账号：

    NACOS_CONFIG_DATA_ID=chein-backend-bootstrap.yaml uv run python -m app.platform.provision_analytics_role

    该命令要求管理员连接。chein_analytics 无超级用户、建库、建角色、BYPASSRLS 或角色成员资格，只读取受保护视图。视图 owner 是独立 NOLOGIN 受限账号。为了禁止临时表，命令会撤销数据库 PUBLIC 的 TEMP 和 public schema 的 CREATE；部署前核对其他应用是否依赖这些公共权限，为必要账号显式授权。

  3. 用 Agent 私有 migration Data ID 安装快照表。沿用已部署的 checkpoint/Agent runtime 账号，不将管理员凭据交给 Agent API：

    cd ../agent
    NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/migrate_analysis.py

    全新安装先按 Agent README 安装 checkpoint。Agent 迁移命令可以重复执行；分析快照权限不需要管理后端的角色授权脚本处理。

  4. 更新 Backend runtime 配置，重启后端：

    配置位置配置
    Backend runtime Data IDAGENT_MCP_ENABLED: true；ANALYTICS_ENABLED: true；ANALYTICS_DATABASE_URL 指向同一 ERP 数据库的 chein_analytics；ANALYTICS_STATEMENT_TIMEOUT_MS: 5000

    Backend 的现有 AGENT_API_URL 保持 /internal/agent/v1 前缀；快照和刷新接口挂在其 /analysis 下。签名密钥、Agent 数据库和 Redis 使用既有受控配置。示例位于 deploy/nacos/*.yaml.example，不直接把示例密码部署为真实密码。

    MCP 随后端启动，共用后端进程和端口；继续使用现有 npm 启动命令即可。以下命令只预览或发布工具契约到 Nacos，完成后退出，不启动后端。

    首次接入，以及工具清单、参数 Schema、契约元数据或服务地址变化时，需要发布新版本并更新 Agent 的版本配置。日常重启或仅修改工具内部实现、保持契约不变时，无需重新发布。Nacos 中已有工具的启用/禁用开关由调用时复验，无需因此发布新版本。

    在 backend/ 预览 MCP 契约；示例 1.3.0 必须是尚未发布的新版本，地址使用 Agent 实际可访问的后端 /mcp（可填写 Agent 能访问的 Tailscale IP，保留端口与路径）：

    NACOS_CONFIG_DATA_ID=chein-backend-runtime.yaml uv run python -m app.modules.agent_tools \
      --edition suite --name chein-backend-tools --version 1.3.0 \
      --endpoint "http://<backend>:8000/mcp"

    预览包含 ERP 统计和四个分析工具。核对后在同一命令末尾加 --publish 发布到 Nacos；不能覆盖现有版本。完成或取消正在执行的 Run 后，修改 Agent runtime 中现有服务项的版本与地址，不重复添加同名服务，然后重启 Agent：

    AGENT_MCP_SERVERS:
      - name: "chein-backend-tools"
        version: "1.3.0"
        endpoint: "http://<backend>:8000/mcp"
    AGENT_ANALYTICS_URL: null

    MCP 模式不需要单独的分析 URL；工具组不完整或被撤销时不注册分析工具，既有调用失败关闭。恢复旧 Run 时工具摘要变化要求新建 Run。新增类似只读接口的开发接入规则见 模块指南。

  5. 启用 ERP/Analytics 模块权益，再通过角色管理授予 agent:chat、erp:statistics:query、analytics:query，以及需要的 analytics:chart:read/create/update/delete/refresh。配置 owner 数据范围及仓库授权。菜单隐藏不是授权边界；平台超级管理员绕过角色权限检查，也仍需满足租户模块权益。

    平台超级管理员可在“系统管理 → 租户中心 → 套餐管理”的目标套餐行点击“模块权益”，开启“数据分析与图表”。左侧菜单实际名称是“套餐管理”，页面路径为 /system/tenant-plans。这会授权使用该套餐的所有租户，无需逐个用户开通；已有租户例外仍优先于套餐设置。

    只需当前租户使用时，在“租户管理”的目标租户行点击“模块权益”，对“数据分析与图表”选择“单独授权”并填写原因。默认租户也提供该入口。页面展示套餐权益、当前有效租户例外、租户启用开关及可用状态；单独授权或禁用是持续生效的例外，不改变角色权限。若状态显示“租户已停用”，还需打开“租户启用”。模块未就绪时应排查迁移/模块状态，不能通过角色授权解决。

    自动化或维护场景也可在后端 /docs 登录授权后使用现有接口，或用当前访问令牌调用 API。先读取 GET /api/v1/tenants/me，取 is_current: true 条目中的 tenant.id，只为当前租户启用 Analytics：

    curl --request POST 'http://<backend>:8000/api/v1/platform/modules/tenants/<当前租户UUID>/overrides/analytics' \
      --header 'Authorization: Bearer <当前平台超级管理员访问令牌>' \
      --header 'Content-Type: application/json' \
      --data '{"effect":"grant","reason":"为当前租户启用数据分析与图表能力"}'

    该接口记录操作人和审计、刷新权限缓存，每次调用新增一条例外记录；不要重复执行已经成功的授权。若希望同套餐的所有租户都可用，则改用 PUT /api/v1/platform/modules/plans/<套餐UUID>/analytics，JSON 为 {"is_enabled":true}，无需同时新增租户例外。ERP 权益缺失时使用同一接口管理 erp。

    若仍返回 TENANT_MODULE_DISABLED，调用 PUT /api/v1/platform/modules/tenants/<当前租户UUID>/analytics，JSON 为 {"is_enabled":true}，启用租户模块偏好；该接口不能代替权益授权。完成菜单同步和授权后重新登录，开始新对话验证。无需因此重新发布 MCP 契约。

  6. 验证“展示本月净销售金额趋势”，检查指标口径、图表与表格、个人收藏、刷新、继续分析及撤权。当前 Qwen聊天模型和决策模型配置无需为规则查询新增模型。未来 Higress 仍只替换既有模型接入配置，分析数据库不经过模型网关。

保留期与回滚​

传输兼容窗口​

旧 /api/v1/analytics/internal/* 和 AGENT_ANALYTICS_URL 保留一个迁移发布窗口：只有 AGENT_MCP_SERVERS: [] 时才使用 HTTP。MCP 已配置时，无论 URL 是否保留、工具禁用、Schema 漂移或网络错误，都不会自动回退 HTTP。HTTP 接口仍使用同一 ERP Provider、权限与预算；本轮不删除旧入口。待旧 Agent 配置和 Run 全部迁移后再单独审计删除。

这次传输改造没有新增数据库迁移、运行时依赖或前端协议；已有 ChartSpec、快照与收藏继续使用。首次启用仍需上述数据库初始化。回滚传输时显式清空 MCP 列表并配置旧分析 URL，再重启 Agent；它也会把 ERP 统计恢复到旧 HTTP 模式，操作前先完成或取消旧 Run。

定期由受控维护作业运行清理命令；API 不隐式执行管理员清理：

# Agent maintenance credential；只清理 Agent 快照
cd agent
NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/cleanup_analysis.py
# Backend bootstrap credential；只清理 ERP 审计
cd ../backend
NACOS_CONFIG_DATA_ID=chein-backend-bootstrap.yaml uv run python -m app.platform.cleanup_analysis_audit

关闭 Backend ANALYTICS_ENABLED，在 Nacos 禁用分析工具并将旧 Agent AGENT_ANALYTICS_URL 设为空，停止新查询和刷新；不用禁用同服务的 ERP 统计工具。保留表、快照、审计及收藏定义，已有 ERP/RAG/聊天路径与 ChartSpecV1 继续兼容。管理员可撤销分析账号连接权限。数据库 downgrade 会删除对应收藏表、审计及视图，只能在备份和依赖审计之后执行。

本地验证与剩余门禁​

使用 PostgreSQL 18 与 Redis 的隔离本地实例，未使用现有应用数据库进行写入。测试中真实使用 chein_analytics 验证基础表/写入/提权/临时表拒绝、跨租户与 owner 范围、整单仓库限制、退货扣减、超时与连接清理；真实 SQL 取消和审计；Agent runtime 快照 owner RLS、不可变权限、重复工具调用与过期；收藏撤权和并发更新。

执行并通过：Backend Ruff 与受影响模块/路由测试；Agent Ruff 与完整 pytest（一个既有外部集成测试跳过）；前端类型检查及 Vitest；Platform、ERP、Analytics Alembic check；新 ERP/Analytics revision 升级—回退—升级；Base、Items、Suite 构建。具体批次记录保留在本轮任务输出，派生产物不作为源码提交。

真实浏览器使用受控 REST/SSE 测试数据，验证聊天图表、收藏保存/查看、精确表格、刷新失败、撤权移除、完整/浮动聊天和亮/暗/手机布局。它验证前端接线，不证明真实 Qwen 能稳定生成正确 QuerySpec。

独立启动本地 Backend 与 Agent API，使用正常登录与会话校验，真实完成签名委托查询、快照读取、收藏创建、刷新、继续分析上下文解析和删除。Backend 使用 app_runtime，查询使用专用只读账号；该 HTTP 验证未调用 Qwen。

2026-10-10 MCP 改造另行验证真实 FastMCP HTTP 服务与 LangChain MCP Adapters：签名、目录、查询、scope、取消、ToolRuntime 调用 ID、有界图表引用、Schema 校验及 Nacos 撤销后无 HTTP 回退。SQL 执行器通过 MCP 装配调用专用只读数据库，并验证审计和当前业务撤权。Nacos 目录在协议测试中使用受控替身；新 MCP 版本尚未发布到用户环境，不能据此声称生产实联已完成。

未执行：真实 Qwen/Decision 业务评测、Higress 实联、目标环境部署、远端 CI、镜像扫描/签名、生产吞吐和 N-1 演练。Docker daemon 不可用，未验证容器启动。设计 F 的决策风险评测与缓存、G 的自由候选 SQL/JOIN/CTE/额外图形继续延期，当前入口拒绝这些结构。
