Token 计费与费用控制交付

设计保持 Proposed。本轮用户明确指定继续 P1–P3。P0 账本与 P2 额度已本地实现；P1 网关接线/配置示例和 P3 通知、导出、离线对账、语音计量已实现。真实网关验收、供应商账单接入及 RAGFlow 内部用量契约尚未完成，不能宣称全量费用控制或生产上线。

行为与所有权​

  • 顶层 Agent usage/ 拥有账本、定价、计数器、策略、执行门禁、告警租约与聚合 Worker。Backend 只做当前身份/RBAC/部门目录、BFF 和 Platform 站内信适配，不加入 Edition、不读 Agent 表。无需新增 Backend 数据表迁移。
  • 默认 off，不读计费表、不加额度图节点。observe 记账与提醒；enforce 对 tenant、部门祖先、user 的日/月 hard 策略取最严格约束，soft/observe 只提醒。默认策略对每个实体独立计数，与显式策略同时适用，不是覆盖放宽。
  • 新 Run、恢复、重放、编辑统一在修改执行状态前准入；审批决定在写入前检查。无权限、对象不存在和审批过期仍按原有授权链处理。后续模型调用由 Middleware 和 callback 检查（含原生摘要）；直接决策 HTTP、图片、视频提交与实时语音有显式检查。
  • 已耗尽返回 429 token_budget_exceeded，含 scope_type/period/reset_at/enforcement。hard 新准入无法确认计数返回 503 token_budget_unavailable；运行中的计数读取故障放行并告警，避免破坏 checkpoint。运行中耗尽记录 budget.exceeded，重新打开已关闭的 checkpointer 连接读取最新 checkpoint，按原租约/暂停状态机保存，补额后可续跑；已完成工具不重做。取消竞争仍由租约隔离。
  • 不使用策略缓存，进程间修改可立即被下一次检查读取。日/月按配置时区自然翻转，含 DST；启用后不能原地变更时区而不迁移计数口径。
  • 策略 CRUD 使用 version 乐观锁、租户事务锁及变更前后审计。plan 策略只读；对象必须属于当前租户，租户 ID 由服务端决定。个人费用默认隐藏，租户管理员可用版本化设置开启。个人只读本人，部门负责人仅授权子树；父级绝对值仅向对应可见范围公开。
  • 价格按发生时版本匹配，整数 micro CNY 计价，缓存/推理不重复相加；缺价格仍记 token、费用为空且标记缺价。超级管理员价格目录只允许追加，写入与来源摘要审计同事务；runtime 无直接价格表写权限。不下载或编造价格。
  • agent.budget_status 绑定 thread/run/lease/sequence，前端拒绝乱序或非当前身份响应。最紧额度芯片、80% 提醒、hard 耗尽禁用输入/语音及重置说明已接线，10 秒轮询可发现补额。管理页支持部门树选择、默认策略、超配提示、二次确认、价格历史及告警/拒绝记录。当前计数仅租户用量查看者可见，默认策略可展开各实体；一次返回最多 2000 条计数并显式提示截断。

账本、迁移与生命周期​

0012_token_billing.sql 保持原样；追加 0013_token_control.sql 和降级文件，包含额度事件/可见性设置 FORCE RLS、告警投递元数据、语音分类字段及受控价格追加函数。迁移脚本按序应用，拒绝有 superuser/BYPASSRLS/建库/建角色权限的 runtime。价格函数固定 search_path、撤销 PUBLIC 执行权限；HTTP 层先验证签名价格权限与 Backend 超级管理员资格。

账本 (tenant_id,invocation_id) 幂等；所有 scope 计数与账本同事务更新，按固定顺序在分配 seq 前取得租户锁。聚合与水位同事务，不漏掉晚提交；Worker 独立取得 PostgreSQL leader guard，逐 tenant FORCE RLS 查询。每批 500 条，5 秒轮询；保留期仅清理已汇总记录，每次最多 1000 条。看板仍查询有索引账本，未混加 rollup 口径。

匿名化复用既有 Outbox required consumer，保存幂等回执与 HMAC 墓碑，替换 owner、清除 run/thread；同步清除告警/拒绝事件中的 owner/run/个人 scope，停止这些告警的待发通知。迟到账本回调写入同一墓碑。聚合数值保留。服务密钥兼作稳定 HMAC key，轮换必须有映射迁移方案。

告警在记账事务内去重。默认策略的 period_key 为自然周期加 :实体UUID，保持 (tenant,policy,period_key,threshold) 唯一，避免两个用户互相吞告警。旧 P0 告警缺收件人元数据，不自动重发。

P1 网关与供应商密钥​

deploy/higress/llm-*.yaml.example 提供私有聊天路由、key-auth、ai-proxy、宽松 token 熔断、无正文统计、入站/出站清理和发布证据模板。只有占位密钥及镜像摘要，不能直接当作生产清单。必须从已审核构建取得不可变 OCI digest；固定源码 commit 不是插件镜像摘要。

Agent 仅在 opt-in 且目标 origin 完全匹配时发送可信身份头；Qwen 每实例固定当前 Run 身份，在实际调用时区分 main/summary/subagent/auxiliary。System One 仍使用专用决策协议，需独立透传路由；没有把它假装转换成 Chat Completions。直连媒体供应商不收身份头。聊天网关模式关闭 SDK 自动重试；429 持久化并返回 gateway_rate_limited，与额度耗尽区分。

官方固定源码确认 限流规则曾在不改版本号情况下变为 all-match OR，故必须验证实际 artifact。限流缺身份头可能绕过对应规则，私有路由仅允许可信 Agent/Worker，不能对浏览器公开。key-auth 按整个 Authorization 头匹配，配置包含 Bearer 前缀；真实供应商 key 只在网关侧保存。

transformer 默认 AUTHN 阶段早于统计，出站清理显式改为默认阶段低优先级。此顺序尚未在目标环境验证；必须检查 effective config 并在上游抓包证明五个身份头均被删除后才能启用。统计插件关闭含问答正文的完整默认属性，使用 numeric response defaults 与有界身份引用日志，不把身份放进 tracing 或高基数 metrics labels；生产日志需显式配置 FILTER_STATE 字段，不能只配 attributes 就声称已采集。

P3 实际范围与限制​

路径实际行为尚需外部证据
主模型、摘要、子图、继承 callback 的辅助模型provider Usage；缺失/取消时本地估算，标 estimated，callback ID+role 去重真实取消流和网关同小时对账
决策 HTTP、图片优化/生成、视频完成可信身份检查；决策无 Usage 估算；成功图片按张；视频固定 task ID 去重，优先实际整数秒超时不明提交与供应商实际计费；禁止盲重试
实时语音response.done 按 provider response ID 去重，包括 canceled；音频 token 是输入/输出子集，同一账本行计价；解析/记账失败隔离真实 Qwen 分类 Usage、打断及会话异常结束补账；缺分类/缺价格不猜费用，缺 Usage 不伪造秒数
语音额度连接前准入、主动创建回答前检查、音频输入最多每秒检查一次；避免逐 PCM 帧访问数据库实时在途回答仍可能超支，需要负载与供应商取消验证
RAGFlow Memory现有接口没有内部提取/Embedding Usage；适用 hard 策略时拒绝推理/搜索，提交任务保持 PENDING/RETRY_WAIT 并标 MEMORY_USAGE_UNAVAILABLE，不增加次数、不重放不明任务服务端可归因 Usage 契约后才能完整纳管；observe/soft 仍有未计入费用。旧 worker 无部门声明时对未知 hard 部门策略保守关闭
告警通知独立开关；Worker 租约、退避重试；Backend 重验活跃租户/成员，个人→本人、部门→负责人、无负责人→额度管理员，站内信 UUID 幂等目标 RBAC 收件人和实际站内信投递联调
CSV租户查看权限，最多 93 天/1000 组或事件，超限拒绝；流式输出、转义表格公式、no-store，写审计大数据量负载验收
对账离线归一化模型总量 JSON；同时间窗比较输入/输出 token，超偏差退出码 2，输出 actor/来源摘要；费用保留供应商折扣/赠金差异，不回写原账本生产 Prometheus 提取、日志归因、真实供应商账单及告警平台接入
已确认漏计受控 CLI 追加 usage_source=gateway，复用原 invocation ID、tenant RLS、原子计数与审计，重复不改变既有记录人工核对具体调用与发生时部门快照，不能拿总量差直接补分户账
预占reservation_assessment 在输入/输出上界均已确认时给并发在途 token 上界，任一未知返回未知未启用 reservation；真实 p99/成本上界测量后再决定

预算使用已提交消耗。并发在途请求、250ms 记账失败、缺价、未纳管服务都可能造成超额；当前功能不是精确的预付余额或供应商账单。缺价格不得当作免费成本。P2b ext-auth gateway-check 未启用，需压测和故障语义证据后再实施。

启用与回滚​

  1. 保持 off，迁移专用 Data ID 执行：

    cd agent
    NACOS_CONFIG_DATA_ID=chein-agent-migration.yaml uv run python scripts/migrate_token_billing.py

  2. 先发布 Agent（接受新旧 delegation），再发布 Backend（当前成员部门祖先链、深度≤12/环检测、负责人子树≤200），最后生成并发布同 Edition 前端、按既有流程播种 RBAC。旧声明无部门，只参与 tenant/user，不捏造历史归属。

  3. Agent/Backend 配置同一个 ≥32 字符生命周期服务密钥；先 observe 和人工审核价格。启动独立 Worker：NACOS_CONFIG_DATA_ID=chein-agent-runtime.yaml uv run python -m chein_agent.usage.aggregator。runtime 不得包含迁移凭据。

  4. 在额度管理页配置策略、验证权限与通知收件人，再通过 Nacos 启动加载设 enforce 并重启；不是热切换。通知另设 AGENT_TOKEN_BUDGET_NOTIFICATIONS_ENABLED=true 与 Backend /api/v1/internal/token-budget/notify 的私网 URL。

  5. 网关通过 llm-release-contract.yaml.example 所有目标门禁后，配置 AGENT_LLM_GATEWAY_ENABLED、AGENT_LLM_GATEWAY_ORIGIN；聊天 base URL 同源，API key 换成网关服务 key。直连回滚同时关闭 gateway enabled。

  6. 价格可在超级管理员目录追加，或使用迁移专用配置执行 scripts/import_token_prices.py --file <已审核JSON> --actor-id <UUID>。区间不得重叠；已有开放区间需要单独审核封口方案，不能覆盖历史成本。

  7. 受控运维配置执行离线对账：

    uv run python scripts/reconcile_token_usage.py --file /tmp/reviewed-model-totals.json --from 2026-11-01T00:00:00+08:00 --to 2026-11-01T01:00:00+08:00 --source gateway --actor-id <UUID> --output /tmp/reconciliation.json
    uv run python scripts/import_gateway_usage.py --file /tmp/confirmed-missing-calls.json --actor-id <UUID> --confirmed-missing

    对账也可 --source invoice，默认容差 100 basis points；输入 schema 见 usage/reconcile.py::ExternalTotal。补录 schema 见 scripts/import_gateway_usage.py::MissingCall，仅接受逐调用证据，保留原 invocation ID，不替换 estimated/provider 行。两命令要求受控 operator/migration 配置，实际账本访问仍使用受限 runtime 和逐租户 RLS。部分调用已成功而后续失败时可用相同文件重试。

  8. 回滚先设 observe 停拦截或 off 停计量、关闭通知/网关开关并重启，保留账本、checkpoint 和审计。迁移 downgrade 只允许空计费表，禁止以删历史作为普通回滚。

2026-11-03：修复额度 BFF 重复路径​

实际 Agent 日志出现 /internal/agent/v1/internal/agent/v1/token-budget/... 的 404。AGENT_API_URL 已包含 /internal/agent/v1，通用 _proxy_agent 按相对路径追加；额度 BFF 错误地再次传入完整前缀。platform_token_budget/router.py 的状态、用量、价格和管理命令入口统一改为 token-budget/... 相对路径，保留既有权限、委托签名和查询参数，不改全局 Agent URL。公开 HTTP 契约、数据库、依赖与生成客户端均无变化。

tests/platform/test_token_budget.py 新增四条实际 HTTP transport 回归，检查最终路径只有一个 Agent 前缀、委托头和用量查询参数。以禁用 Nacos/后台 Worker、数据库指向不可连接地址的环境执行 uv run pytest tests/platform/test_token_budget.py tests/platform/test_agent_ui_router.py -k 'not batch_permissions_use_one_query_and_recheck_tenant_and_revocation' -q：28 passed、1 deselected；排除项直接依赖清理型 db fixture，未访问开发/共享数据库。uv run ruff check app tests 通过。真实账号下额度页面的完整联调仍待验收，外部门禁保持上节状态。
