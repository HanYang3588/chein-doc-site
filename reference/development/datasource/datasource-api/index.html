数据源 API 与数据库

本地实现入口为 backend/app/modules/datasource/routes.py，类型源为同模块 public_api/dto.py；完整契约以 Suite OpenAPI 为准，通过 pnpm generate:api -- --edition suite 生成前端客户端。设计来源和 DataVines 原接口见 设计提炼，部署及验证见 交付说明。

公共规则​

基址 /api/v1/datasource；沿用登录 JWT、可信 tenant 和 require_module_access，请求不能指定 tenant/owner。以下权限均省略 datasource: 前缀。分页 {items,total,page,page_size}，默认 50，上限 100。资源 ID 为 UUID；配置更新使用 expected_revision，冲突返回 409。成功为 DTO，错误由现有全局处理器返回 code/detail，错误码以 DATASOURCE_ 开头。

方法、相对路径输入输出权限

注册类型为 mysql,postgresql,clickhouse,doris,starrocks,databend,mongodb,oracle,sqlserver,dm,hive,impala,presto,trino,maxcompute。注册不代表已完成厂商实联验收；部署前置条件和验证状态见交付说明。MySQL connection 为 {host,port:3306,database,username,charset:"utf8mb4",tls:true}，PostgreSQL 使用 {host,port:5432,database,schema_names:["public","agent"],username,tls:true}；其他类型采用 /config/{kind} 返回的字段与默认值，不复制 MySQL 端口。Oracle 的 database 为 Service Name，Presto/Trino 为 Catalog，MaxCompute 为 Project，MongoDB 的 database 同时作为认证库。拒绝未知字段；主机不能填写 URL；不接受 JDBC URL、驱动类、JAR 路径、任意 SQL 或自由驱动参数。password（MaxCompute 为 AK Secret）仅写入；编辑省略表示保留，空串/星号掩码不可作为替换密码。ConnectionPublic 返回 name,type,connection,has_password,revision,last_test_status/code/at,last_synced_at,created_by,creator,created_at，不返回密码或密文。

PostgreSQL 测试可提交 connection.schema_names: [] 发现 Schema；成功的 TestResult 新增 schemas: string[]（其他类型为空）。返回有 USAGE 权限的非系统 Schema，不返回密码。创建/修改 PostgreSQL 连接的 schema_names 最多100个且不能为空；未提供新字段时兼容原 schema_name 单值。GET /catalog/tables 新增可选 schema_name 查询参数；表列表 properties 保留 schema，数据库根 properties.schemas 为最近成功发布的选择范围。客户端树按该范围分组，各组沿用50项分页；完整身份包括数据库、Schema、表名，EntityPublic.id 仍是操作入口。

测试连接返回明确类别：success、network、timeout、authentication、database_missing、schema_required（保存空选择时422）、schema_missing、schema_changed、permission、tls、unsupported、driver_unavailable、timeout_unavailable、budget、unknown，message 为安全提示。主机与端口由页面指定，不设应用级网络/端口白名单。新草稿的测试结果不伪装成已保存版本的健康状态；只有存量源参数一致且复用原密码时记录 tested_revision；PostgreSQL Schema 发现请求若复用同一连接参数与原密码，且确认保存范围仍全部可访问，也记录该保存版本的连接测试状态。

EntityPublic 含 id,connection_id,parent_id,kind,physical_name,catalog_name,source_comment,presence,revision,properties,last_synced_at,config,recommended。列表不重复携带全表字段与外键，详情按需读取。字段 properties 包括 type,length,precision,scale,ordinal,nullable,default,primary_key,comment,generated。

单表配置启用时可提交 dependency_revisions:{目标UUID:配置版本}，必须与当前缺失依赖集合一致，所有目标与主表原子启用。

config 共同字段：business_name（200）、description（2000）、tags（最多20个，每个50字符）、revision；表独有 enabled、ontology_class_iri；字段独有 exposed、mask_policy（none/redact/last4）、ontology_property_iri。保留的 IRI 字段只存引用标识，不调用本体模块。批量 tags 默认替换，tag_mode:"add" 合并。表缺失或配置版本不匹配不能修改。

TaskPublic 不暴露连接参数或 staging：id,connection_id,status,error_code,summary,created_at,finished_at；状态 pending/running/succeeded/failed/expired。summary 在处理中提供 completed/total，成功时给 tables/missing。完整快照成功后原子发布，失败保留旧目录；missing_or_inaccessible 不能被解释为已证明物理删除，删除后同名重建生成新目录身份。

预览只查询启用表的 exposed 字段；默认隐藏 password/secret/token/phone/mobile/id_card 等名称命中项，可由有权用户配置。最多200列，单元格最多1000字符并按行列规模收紧，结果另有1MiB检查。值通过 CAST 转为字符串以避免大整数精度丢失，NULL 保持 null；二进制/大文本按相同字符预算截断，不能用于原样导出。无排序保证；结构变化、禁用表、权限撤销时拒绝返回样本。

数据库所有权​

PostgreSQL schema datasource，独立 Alembic 版本表 public.alembic_version_datasource，初始 revision datasource_baseline_v1。后续 datasource_enabled_defaults_v2 一次性启用未修改过的旧默认表（active table、enabled=false、config revision=1）；已保存的配置和字段暴露状态不变。完整建表、索引、字段注释和 RLS SQL 见 迁移生成的 DDL（未发布资料）。部署必须运行迁移编排，不能把该 SQL 当作绕过迁移的启动脚本。

表所有者及用途关键约束/索引
connection数据源、类型化非敏感参数、加密密码、版本和最近测试状态tenant+name 唯一；tenant+type+created_at 索引
catalog_entitydatabase/table/column 统一目录，源 properties、父目录、结构版本、存在状态tenant+connection 复合外键；parent 同源同租户；active 路径哈希唯一；父目录分页索引
entity_config人工业务名、描述、标签、启用、暴露、脱敏及 IRI 扩展tenant+entity 唯一；实体复合外键；配置 revision
entity_relation一等外键关系，目标实体可空、原库表名、有序字段对和规则source/target 同租户同源外键；source+constraint 唯一
sync_task可恢复采集任务、租约、attempt fencing、staging、配置版本与摘要同源最多一个 pending/running 的部分唯一索引；状态索引
schema_change每次完整采集后的 added/changed/missing_or_inaccessible，before/after同源外键；source+created_at 索引；不保存预览行

六张业务表全部 FORCE RLS；无 tenant scope 时没有可读行，跨租户写入被策略和复合外键阻止。ORM 同时要求 DatasourceUow，禁止 bulk DML 与修改 tenant_id。runtime 授权通过现有 Platform 幂等角色脚本完成，API/Worker 不持有迁移管理员凭据。降级删除整个模块目录和配置，属于数据丢失操作，必须先备份。
