系统与个人知识库管理

状态：知识治理、组织授权与检索闭环代码已实现；生产启用与真实 RAGFlow 联调以部署步骤为准，不代表已上线。

管理入口收口为 知识库、检索测试、Agent 知识配置。知识库页面使用 Ant Design 原生 Tabs 切换我的、共享给我、团队、系统和全部；全部仅表示当前用户有权限访问的库。默认打开我的，分类保存在 URL 中；切换分类重置表格分页/筛选。列表展示资源权限对应的使用者/编辑者/管理者，按钮仍同时检查模块 RBAC 和资源 ACL。

操作顺序为知识库列表 → 文档管理 → 上传/解析/预览 → 共享与权限 → 单库检索测试。详情保留绑定和有 debug 权限者的本人记录；租户级参数只在独立检索测试页维护。独立页包含跨库测试、租户设置（configure）及本人日志/缺口（debug），选择器只出现在测试 Tab。Agent 集中配置独立保留，取消工作台重复入口。系统库创建仍要求维护身份，团队库仍要求有效部门。

复用 ProComponents 和原生 Ant Design，无新增 UI 依赖或全局 CSS。参考 Dify 知识设置与文档管理与 RAGFlow 0.27.2 知识库列表的库列表、库内维护和检索测试分层，保留 Chein 权限模型。

模块使用 NavigationSpec.is_visible 声明入口显示状态。旧分类路径隐藏但保留菜单 ID、套餐/角色关联及受控组件映射；menus/me 返回已授权且激活的页面/目录（包括隐藏路由），不返回按钮。前端用 hideInMenu 隐藏入口但保留路由。隐藏不是授权，未分配角色、停用页面和未授权模块继续失败关闭。

以上操作同时受模块权益和对应 RBAC 权限控制。取消共享、停用或删除后的新检索和原文下载重新鉴权；客户端和模型提供的 Dataset ID 不能代替授权。知识正文不会出现在后端运行日志中。

统一权限抽屉同时维护私有、指定主体、当前租户公开范围及 USER/ROLE/DEPARTMENT 的 READ/WRITE/MANAGE 授权。主体来自当前租户有效目录，支持远程搜索，并按 ID 回查已有授权名称。所有者保留管理权限；部门库的部门成员默认 READ。私有范围保存会明确清空显式授权，指定主体范围至少需要一个授权，公开范围可以额外授权编辑者或管理者。重复主体不能保存，目录查询失败可重试。旧共享接口在存在组织授权时拒绝写入，避免覆盖新权限。平台系统库继续单独维护草稿/发布，不进入租户权限抽屉。

实现与数据所有权​

  • backend/app/modules/knowledge/ 拥有知识库元数据、分享、文档状态、RAGFlow 映射、迁移及同步逻辑；平台只提供身份、成员目录、授权与 Web 集成面。
  • ModuleDefinition.navigation/default_user_permissions 是代码维护的模块菜单和默认角色权限来源。Suite Edition 包含 Knowledge，其他 Edition 不装配其后端路由。
  • 数据位于 knowledge.base/grant/document 和独立全局 system_base/system_document。租户 UoW 防止归属修改、跨租户写和 ORM bulk DML；强制 PostgreSQL RLS 进一步约束 runtime 角色。Session 退出时移除知识对象，避免复用 Session 时从缓存读取上一租户对象。
  • 一个管理知识库对应一个 RAGFlow Dataset。RAGFlow 保存最终文件、分块和索引；管理数据库保存有上限的待上传内容，成功上传并启动解析后清除。
  • API 在同一事务写入元数据与 KnowledgeSyncV1 Outbox 事件。既有 Worker 执行外部效果，解析进度由既有 Schedule Worker 查询。同步消费者锁定知识库，并通过稳定唯一外部名称恢复超时后的创建/上传。
  • 页面批量上传逐文件排队，单文件失败不阻断后续文件；上传接口在线程池处理同步数据库和文件读取，避免行锁等待阻塞 API 事件循环。事务已提交时 UoW 退出不再取连接执行清理 SQL，连接池超时也不会在清理阶段重复等待；健康的活动事务仍恢复租户与系统写权限。
  • 删除先令本地资源不可用，然后删除 RAGFlow 数据，成功后清理本地记录。同步失败保留状态和重试入口，不把失败显示为成功。

Agent 动态使用​

没有可用文档时返回 no_knowledge，不向 RAGFlow 发送空允许列表。Agent 通过固定的版本化内部 HTTP Facade 调用本模块，不导入后端 ORM。新引用使用 Chein 库/文档 ID，经 /api/v1/agent-ui/knowledge/documents/v2/{base}/{document} 实时授权；旧格式仅用于历史只读兼容。

AGENT_KNOWLEDGE_URL 启用后优先使用动态模式，失败时不回退旧静态资料。连接参数只在初次启用/改地址时需要进程重启；日常知识和共享维护直接生效。

调研依据与当前边界​

RAGFlow 官方 HTTP API提供 Dataset、上传、解析、分块、检索和删除。本实现按 0.27.2 API 核对；该版本 Python SDK仅支持 3.13，因此 Python 3.14 后端使用现有 httpx 调用官方接口。Chein JWT/分享关系由管理系统维护，不假设 RAGFlow 的服务账号 API Key 自动带有最终用户 ACL。

页面分库、文档继承库权限、明确上传状态的设计参考 Dify 知识管理、FastGPT 文件权限及 RAGFlow 资源权限。

支持文件和 Markdown 笔记，用户可复制明确选定的知识内容保存为笔记；维护者可编辑分块与文档 Metadata。自动沉淀对话、文档版本替换、审核工作流和大规模分批召回尚未实现，不把私人对话或模型回答自动发布为系统知识。容量和部署前置条件见部署文档。

治理与检索工作台​

文档抽屉支持分页分块、Metadata 编辑、实际处理记录和原文预览。PDF 与文本提供原文预览；Office 文档展示解析文本并提供原文下载，不承诺还原 Office 排版。处理记录仅保留最近 100 次真实事件，旧文档没有的历史不会补造。工作台提供授权知识库搜索/分页选择与结构化检索 Trace，详情的统计和记录仅针对当前库、当前用户。Agent 知识管理集中配置可管理知识库的绑定策略、优先级和路由说明；只读库不可修改。完整权限、当前功能与限制见实施报告。

文档上传使用工具栏原生 Upload 按钮，知识笔记入口并列；不再展示整块拖拽区。Knowledge 模块在工作区按 Edition 与权限延迟装配上传队列，顶部上传图标打开原生 Drawer / Table，分页展示各知识库文件的排队、上传、已提交、失败状态。队列逐文件发送，关闭详情或切换业务页面仍继续；租户/用户变化、退出登录或权限撤销时中止未完成的请求与排队文件，不跨身份重放。上传列表仅保存在当前页面运行期间，刷新或关闭浏览器不能恢复尚未提交的本地文件；已提交文档由后端继续同步与解析。请求超时可能已被后端接收，失败详情提示先核对文档列表，避免直接重试造成重复。解析进度仅在解析中的文档显示，当前分页没有解析任务时隐藏进度列；元数据列默认隐藏，可在原生列设置打开，元数据编辑仍在文档详情中。

文档列表仅在当前页存在待同步、解析中、删除中或更改同步任务时每 5 秒静默查询，更新相同文档的处理状态、进度、分块数和错误；不调用表格 reload，不替换名称、来源、大小和元数据，不重置勾选、分页和滚动位置。未变化的行保留原对象，分页或手动刷新后的旧轮询响应被丢弃，请求未结束时不重叠轮询，离开详情后中止轮询。完成后停止自动查询；上传批次完成、用户操作及手动刷新仍加载完整列表。其他成员新建或编辑的文档需手动刷新查看；知识库总列表仅在当前页存在待处理知识库时启用原生轮询。

文档表格为文件名预留更多宽度，长名称省略并通过原生 Tooltip 展示全文；大小和分块数右对齐，检索开关居中。操作按钮保持单行，桌面固定在右侧，窄屏通过原生横向滚动查看；英文操作列相应加宽，失败文档的重试与删除并排展示。

知识管理的说明文字使用 Ant Design 原生 Tooltip：info 图标放在分类栏、对应标题、表单标签或操作旁，悬停、键盘聚焦或点击查看。错误、未配置、解析及同步失败继续直接显示；发布和删除确认保留明确的影响说明。

知识库列表通过 ProTable 原生 search.optionRender 将新建按钮放入查询操作区，保留原有创建权限与未配置禁用状态。名称、所有者文本框最多 240px，状态和所有者类型下拉框最多 160px，窄屏自动缩小、换行；表格刷新、密度和列设置仍使用原生工具栏。
