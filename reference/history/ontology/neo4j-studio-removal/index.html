Neo4j 语义本体页面退役

仅删除独立的 /ontology-neo4j 工作室及其专属实现，保留 /ontology-builder OWL 可视化构建器。此前双工作区与 Legacy 工作室退役文档保留为历史记录；当前页面入口以 ModuleDefinition.navigation 和 page registry 为准。

删除范围​

  • 前端 Neo4jStudio.tsx、样式、测试及仅由它使用的 ReasoningPanel.tsx。
  • modules/ontology/neo4j 页面注册、menu.ontologyNeo4j 菜单声明和 ontology.neo4j.* 双语文案。旧组件及 #/、.vue 形式不再可选或解析。
  • 下列专属 HTTP 接口及 SemanticImport、SemanticValidation DTO、无其他调用方的 Neo4jOntologyProvider.semantic_configuration()。
方法已移除路径（前缀 /api/v1/ontology）
POST/semantic/import-preview
POST/semantic/validate
GET/semantic/configuration
GET/networks/{network_id}/versions/{version}/semantic-export
GET/providers/health
GET/templates/catalog

按本次显式退役要求直接移除，不保留兼容窗口；旧客户端收到 404。OpenAPI 客户端和 Build Manifest 通过仓库生成器更新。

保留边界​

  • OWL 构建器、画布、右键编辑、数据源目录导入、工作区绑定、发布、导出和 /builder/*。
  • 发布网络、版本、权限、审计、候选、Tenant UoW、RLS 和所有历史迁移及业务数据。
  • Agent 共用的语义查询、发布快照投影、Provider、RDF/SHACL 和 HermiT。ReasoningTask.tsx 仍由 Agent 结果渲染器使用，其测试迁到同目录。
  • ONTOLOGY_PROVIDER、ONTOLOGY_NEO4J_ENABLED、ONTOLOGY_FALLBACK_ON_ERROR、NEO4J_* 配置及 Neo4j/n10s 依赖。它们供构建器及授权运行时使用，不能随旧页面删除。本次没有页面独占的数据库连接配置可删。

已有数据库的菜单清理​

新环境播种仅注册 OWL 构建器。已有数据库不会因源码删除自动丢弃历史菜单，部署后须由维护者执行清理。执行前备份 menu、rolemenu、tenantplanmenu，并确保已播种 /ontology-builder 菜单。

在仓库根目录执行，不必重复填写数据库地址、账号或密码，也不需要 psql：

bash scripts/ontology-setup.sh cleanup-neo4j-menu

命令复用现有 Nacos 加载器和 configure_admin_database()，默认读取 chein-backend-bootstrap.yaml 的 POSTGRES_ADMIN_URL，兼容已有维护配置中的 POSTGRES_URL。Nacos 地址、namespace、group、认证沿用现有后端引导配置；已定制的维护 Data ID 沿用 ONTOLOGY_BOOTSTRAP_DATA_ID。不修改 Nacos，不将维护凭据注入 API/Worker，不自动迁移或全量播种。配置缺失、权限不足或菜单前置条件不满足时非零退出，日志不输出连接串或密码。

Python 维护入口直接执行同一份 SQL（未发布资料），不另维护一套删除逻辑；手工 psql 执行方式仍可使用。

脚本精确匹配旧路由和已知组件形式，事务内迁移共用权限按钮及角色/套餐授权至 OWL 菜单，再删除旧菜单和关联。保留自定义同路由组件、OWL 菜单和排序。缺少唯一 OWL 菜单、自定义权限或未知子菜单均整笔回滚；支持重复执行。无需修改运行时配置，不删除本体或图数据。

验证与部署边界​

菜单脚本通过 python3 scripts/test_remove_business_ontology.py 在新建、私有 socket-only PostgreSQL 集群验证，未对现有业务数据库执行。测试通过 Python CLI 使用维护连接实际执行同一 SQL，覆盖旧菜单删除、OWL/共用权限保留、授权迁移、异常回滚、幂等和日志脱敏。python3 scripts/test_ontology_setup.py 验证维护 Data ID 路由、参数校验与错误退出；后端 test_admin_db.py、test_cleanup_neo4j_menu.py 验证连接选择和失败日志脱敏。
