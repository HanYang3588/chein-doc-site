销售业务：订单 -> 出库 -> 退货

状态：操作与事实说明（以 sale_routes.py、sale_stock_routes.py 为准）。

适用范围：销售订单、销售出库、销售退货。

相关：01-数据地图.md、04-库存管理.md、 05-财务结算与核销.md。

1. 单据链与数据流​

销售订单 XSDD (sale_order)
   └── 销售出库 XSCK (sale_out)         库存 -，回写订单 shipped_quantity
          └── 销售退货 XSTH (sale_return) 库存 +，回写出库 returned_quantity 和订单 returned_quantity
                 └── 收款单 SKD (finance_receipt) 核销 sale_out（正方向）/ sale_return（负方向）

与采购完全对称，差异只有三处：

  1. 往来单位是 customer，方向相反（出库减库存、退货加库存）。
  2. 建单时增加最低售价校验：明细 unit_price < product.min_sale_price 直接 409 Sale price is below the product minimum。
  3. 出库表头用 other_deduction（其他扣款，减少总额），退货表头也用 other_deduction。

2. 建单与审批校验​

环节校验失败表现
销售订单客户存在且 is_active409 Customer is unavailable
销售订单明细单价 >= 商品 min_sale_price409 Sale price is below the product minimum
销售订单折扣不超过 product_amount + tax_amount409 Discount exceeds order amount
销售出库订单必须 approved409 Sales order must be approved
销售出库明细数量 <= order_item.quantity - shipped_quantity409 Shipment quantity exceeds remaining order quantity
销售出库库存充足（按商品 + 仓库逐行校验）409 Stock is insufficient
销售退货出库单必须 approved409 Sales return source is unavailable
销售退货数量 <= 出库行可退量，且 <= 订单行可退量建单/改单 409 Return quantity exceeds shipment quantity；审批 409 Return quantity exceeds available shipped quantity

3. 审批时的数据流转​

3.1 销售订单审批​

status -> approved、version += 1、记录 approved_by/approved_at、写审计与事件 erp.sale_order.approved。不产生库存分录。

反向：若任一明细 shipped_quantity > 0 或 returned_quantity > 0，返回 409 Sale order has downstream documents；否则回到 draft。

3.2 销售出库审批（POST /api/v1/erp/sale-outs/{id}/approve）​

  1. 校验出库单 draft + 版本、订单 approved、明细数量在剩余可发范围内。
  2. 过账：每条明细写 stock_ledger（ledger_type = sale_out、delta_quantity = -数量）， 更新 stock_balance；库存不足时整笔回滚并返回 409 Stock is insufficient。
  3. 回写 sale_order_item.shipped_quantity += 数量。
  4. status -> approved、version += 1、写审计、发 erp.sale_out.approved。

3.3 销售出库反向​

前置条件：单据 approved；无下游退货（Sale shipment has downstream return documents）； 无已审批收款单引用（Sales shipment has approved settlement documents）；原分录齐全 （Sales shipment has no reversible posting）；关联销售订单仍存在（Sales order is unavailable）； 订单行 shipped_quantity 不小于本次冲回数量（Sales order shipment quantity is inconsistent）。

执行：写 sale_out_reversal 分录（库存加回）、shipped_quantity -= 数量、 status -> draft、version += 1、审计 reversed。

3.4 销售退货审批 / 反向​

  • 审批：库存增加（ledger_type = sale_return）， sale_out_item.returned_quantity += 数量、sale_order_item.returned_quantity += 数量， status -> approved。
  • 反向：要求无已审批收款单引用、数量可回退；写 sale_return_reversal 分录（库存减回）， 两个 returned_quantity 减回，status -> draft。

4. 排查​

Q：客户欠款 / 已收金额怎么算

出库单表头 settled_amount 是已核销金额，未收 = total_amount - settled_amount （只统计 status = 'approved'）：

SELECT so.no, so.total_amount, so.settled_amount,
       (so.total_amount - so.settled_amount) AS outstanding
FROM erp.sale_out so
WHERE so.tenant_id = '<tenant>' AND so.customer_id = '<customer>'
  AND so.status = 'approved'
ORDER BY so.business_at;

Q：某客户某月销售净额

SELECT (
  SELECT COALESCE(SUM(total_amount), 0) FROM erp.sale_out
  WHERE tenant_id = '<tenant>' AND customer_id = '<customer>'
    AND status = 'approved' AND business_at >= '<from>' AND business_at < '<to>'
) - (
  SELECT COALESCE(SUM(total_amount), 0) FROM erp.sale_return
  WHERE tenant_id = '<tenant>' AND customer_id = '<customer>'
    AND status = 'approved' AND business_at >= '<from>' AND business_at < '<to>'
) AS net_sales;

Q：订单还有多少没发货

SELECT i.line_no, i.product_name, i.quantity, i.shipped_quantity, i.returned_quantity,
       (i.quantity - i.shipped_quantity) AS outstanding
FROM erp.sale_order_item i
JOIN erp.sale_order o ON o.id = i.sale_order_id AND o.tenant_id = i.tenant_id
WHERE i.tenant_id = '<tenant>' AND o.no = '<销售订单号>'
ORDER BY i.line_no;

Q：出库审批报库存不足

按明细逐行核对 stock_balance：

SELECT i.product_name, i.warehouse_id, i.quantity AS requested, b.quantity AS available
FROM erp.sale_out_item i
LEFT JOIN erp.stock_balance b
       ON b.product_id = i.product_id AND b.warehouse_id = i.warehouse_id
      AND b.tenant_id = i.tenant_id
WHERE i.tenant_id = '<tenant>' AND i.sale_out_id = '<sale_out_id>';

注意：stock_balance 是所有出入库（含其他入库/出库、调拨、盘点）累计的结果， 不是只看销售侧；对不上时用 04-库存管理.md 的流水核对方法。
