Langfuse 分阶段实施、性能实验与验收计划

状态：Proposed。P1–P5 本地实现已接线；以下完整性能/业务门槛、生产部署与治理签署仍待验收，当前实现及配置见 实施与启用。 设计契约见总体设计，现状和依赖见审计，外部能力/固定 SDK 行为见调研。

1. 实施边界与依赖​

只在 agent/ 加官方 Langfuse 候选依赖；BFF/业务数据所有者按实际阶段补通用 OTel/公开 DTO。禁止新增跨模块 ORM 导入、通用业务日志系统、任意 SQL Tool、原文采集、后台自动 Worker 或第二 Prompt 发布平台。

P0 是本次静态审计，不等于全部环境验收。用户先授权 P1，随后已授权实施全部阶段。P1 接线与本地证据见 P1 交付，后续本地实现与剩余外部门禁见 实施与启用。实施顺序 P0→P1→P2→P3→P4→按真实需求决定 P5；P1 本身就必须有隐私、取消和故障验证，不能把安全/性能基础留到 P3 才补。

“预计修改文件”中的 [新增] 是规划标记；是否已存在与当前实施证据以 P1 交付及代码为准。负责人角色为建议分工，具体人员待团队指定。

3. 性能实验协议​

3.1 可复现负载和对比矩阵​

本地 Callback 压测、SSE 驱动与 loopback OTLP 故障服务已提供，见 实施与启用。下述完整生产性能矩阵、固定 arrival-rate 服务负载与隔离 CH/Worker 演练仍待执行，尚未改生产配置。

固定容器CPU/RAM、镜像/lock、DB/KB数据快照、租户、权限、Prompt/hash、Qwen模型/温度、环境网络；baseline保留已有ECS Callback，其余关闭Langfuse，避免拿“完全无日志”当现有对照。交错运行baseline/variant至少3轮，先预热200请求，再每单元至少10000请求用于P99；初步冒烟可100请求但不能证明P99。真实付费模型先100–500个合成请求核对，费用上限经批准后再扩；不能为统计样本量无限花费。

3.2 可以直接运行的合成SSE计时驱动​

下面脚本只用标准库，运行于隔离测试BFF，调用当前已核对的 /api/v1/agent-ui/threads、/chat 契约。它会创建N个测试线程，不自动删除，便于核对Trace/Run；实验结束通过已有授权API清理。提前给专用账户配置当前租户与工具权限，真实请求Header从项目外私有环境读取，不在CLI/报告输出凭据。没有合成数据/隔离环境时不要运行。

将代码保存到 /tmp/chein-langfuse-sse-bench.py，用 CHEIN_BENCH_BASE_URL、CHEIN_BENCH_HEADERS_JSON 私有环境指定可信测试BFF与已鉴权Header，CHEIN_BENCH_N/C控制请求与并发。输出只含ID/时序/状态，不记录回答正文；它测客户端首文本事件，浏览器实际渲染TTFT需要前端performance计时。

import concurrent.futures
import json
import math
import os
import time
import urllib.error
import urllib.request
import uuid

base = os.environ["CHEIN_BENCH_BASE_URL"].rstrip("/")
headers = {**json.loads(os.environ["CHEIN_BENCH_HEADERS_JSON"]),
           "Content-Type": "application/json", "Accept": "text/event-stream"}
n, concurrency = int(os.getenv("CHEIN_BENCH_N", "100")), int(os.getenv("CHEIN_BENCH_C", "8"))
assert n > 0 and 0 < concurrency <= n
# 遵循项目内部服务直连行为；不把环境HTTP代理带进对比。
opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))

def post(path, body):
    data = json.dumps(body).encode()
    return opener.open(urllib.request.Request(base + path, data=data, headers=headers), timeout=120)

def run(thread_id):
    started = time.perf_counter()
    row = {"thread_id": thread_id, "status": "incomplete", "first_text_ms": None,
           "chunk_count": 0, "run_id": None, "request_id": None}
    previous, max_gap = None, 0.0
    try:
        with post("/api/v1/agent-ui/chat", {"threadId": thread_id, "message": "合成测试：回复测试完成。"}) as response:
            row["request_id"] = response.headers.get("X-Request-ID")
            data_lines = []
            for raw in response:
                line = raw.decode("utf-8").rstrip("\r\n")
                if line.startswith("data:"):
                    data_lines.append(line[5:].lstrip())
                elif not line and data_lines:
                    event = json.loads("\n".join(data_lines))
                    data_lines.clear()
                    kind = event.get("type")
                    now = time.perf_counter()
                    if kind == "RUN_STARTED":
                        row["run_id"] = event.get("runId", event.get("run_id"))
                    elif kind == "TEXT_MESSAGE_CONTENT" and event.get("delta"):
                        row["chunk_count"] += 1
                        if row["first_text_ms"] is None:
                            row["first_text_ms"] = (now - started) * 1000
                        if previous is not None:
                            max_gap = max(max_gap, now - previous)
                        previous = now
                    elif kind == "RUN_ERROR":
                        row["status"] = "error"
                    elif kind == "RUN_FINISHED" and row["status"] != "error":
                        result = event.get("result") or {}
                        row["status"] = result.get("status") or "succeeded"
    except urllib.error.HTTPError as error:
        row["status"] = f"http_{error.code}"
    except Exception as error:
        row["status"] = type(error).__name__  # 不输出异常正文/URL/headers
    row.update(total_ms=(time.perf_counter() - started) * 1000, max_chunk_gap_ms=max_gap * 1000)
    return row

# 会话准备不计入chat延迟；拒绝跨组共享同一活跃thread。
threads = [str(uuid.uuid4()) for _ in range(n)]
for identity in threads:
    with post("/api/v1/agent-ui/threads", {"threadId": identity}) as response:
        response.read()  # 合成thread元数据，不输出
with concurrent.futures.ThreadPoolExecutor(max_workers=concurrency) as pool:
    rows = list(pool.map(run, threads))

def percentiles(field):
    values = sorted(row[field] for row in rows if row[field] is not None)
    return {str(p): values[min(len(values)-1, math.ceil(p*len(values))-1)]
            for p in (0.5, 0.95, 0.99)} if values else {}

print(json.dumps({"n": n, "concurrency": concurrency,
                  "counts": {s: sum(r["status"] == s for r in rows) for s in {r["status"] for r in rows}},
                  "total_ms": percentiles("total_ms"), "first_text_ms": percentiles("first_text_ms"),
                  "rows": rows}, ensure_ascii=False))
# 在私有环境已加载、P1接线部署到隔离测试环境后执行；报告仅放系统临时目录。
CHEIN_BENCH_N=100 CHEIN_BENCH_C=8 python3 /tmp/chein-langfuse-sse-bench.py > /tmp/chein-langfuse-b1.json

这是最小端到端计时驱动，不是完整压测工具：缺固定arrival-rate、浏览器渲染、Token、CPU/内存/export统计。正式验收按下节补收集，不能拿它单独证明全部性能。故障通过测试专用export代理注入，不改真实模型/ERP/数据库网络；5xx/timeout实验要确认打断的只是Langfuse目的地。模型/Tool负载L1/L2由P1新增的Fake/provider fixtures生成，不以自然语言“请调用20次工具”作为可复现负载。

3.3 指标采集与计算​

4. 候选验收门槛​

全部是待压测/业务确认的目标，不是本次已达到的结果。 先以确定性Fake、相同资源、baseline业务未饱和范围评估；真实模型另报告供应商抖动与覆盖率。

6. 发布与回滚检查​

先发布默认关闭镜像→合成dev启用→staging故障/压测→经业务/安全确认production候选采样；每步保存release/config digest、实际SDK/server/OTel版本、结果与Owner。配置是启动快照，修改Nacos后须受控滚动重启并确认所有worker同版。

出现泄密/性能/兼容性回归：关闭Langfuse、重启或回前镜像；不回滚Prompt/工具/权限策略以掩盖遥测问题。已生成业务数据/RunEvent保持可兼容；反馈表使用扩展式迁移，P4回滚关闭新入口而非删反馈。独立Langfuse服务升级/备份恢复按部署方案处理，禁止down -v或对共享Redis执行FLUSHALL。旧Trace可能残留，按经批准清理策略删，不假装配置关闭即删除历史数据。

Nacos Prompt/模型/检索策略优化发布要独立回滚到先前已审核版本；Langfuse实验与Score仅供证据，不自动写生产latest。新增APM/Collector时回滚仅撤其出口，不破坏业务日志/安全审计和现有AI观测。
