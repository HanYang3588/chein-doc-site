Agent 数据与业务契约设计

状态：Proposed（目标设计）

1. analysis.v1 稳定契约​

analysis.v1 负责把问题转换为受约束的分析意图，读取版本化 Dataset，创建 Snapshot，并产出带引用的 Report。指标口径、金额精度、时区和审核状态由 ERP/业务数据所有者定义；模型只负责候选计划和表达。

跨进程契约使用语言无关的 JSON Schema 或 OpenAPI 作为唯一事实源，再生成 Python、TypeScript 和远程客户端类型。运行时只传 JSON、标量和不透明 Artifact 引用。

核心对象：AnalysisRequest、QuerySpec、DatasetVersion、DataSnapshot、MetricValue、ChartSpec、Citation、AnalysisReport。所有对象均为不可变 DTO，不包含 ORM、Session 或第三方 SDK。

2. QuerySpec 与 Snapshot​

QuerySpec 只能引用已发布 DatasetVersion 的指标、维度、过滤字段、聚合、排序和粒度；时间范围、行数、分组基数、精度和时区都有上限。客户端或模型提交的 tenant_id 不具有身份意义，平台根据 delegated context 注入数据范围。

校验失败返回 QUERY_INVALID。DataProvider 将通过 ERP Facade 执行查询，未来即使使用 SQL，也只能由受控编译器生成。

Snapshot 至少记录：snapshot_id、dataset/version、query_hash、policy_version、source_as_of、schema_hash、checksum、row_count、expires_at 和 data_ref。小结果可内联，大结果进入加密对象存储。Snapshot 不可变、可回放、过期后必须重新授权并生成新 Snapshot。

首期 ERP 数据集使用 erp.statistics.v1：统计摘要提供 today/yesterday/month/year 的采购和销售金额，时间序列支持 purchase/sale、day/month 粒度以及 start/end 范围。接口继续由 ERP 负责审核单据口径、租户时区、owner/warehouse 数据范围和 erp:statistics:query 权限；Agent 只做 DataProvider 适配，不复制交易表或重算业务指标。

3. 报告不变量​

  • 每个权威数字都能追溯到 Snapshot、DatasetVersion 和 Citation。
  • 报告注明时间范围、租户时区、数据新鲜度、过滤范围和假设。
  • 图表使用声明式 ChartSpec，不保存可执行 JavaScript。
  • ReportValidator 确定性复核金额、单位、排序、引用和数据质量。
  • 数据 degraded、过期或不完整时必须显式标记，不能输出无依据的确定性结论。

4. L0-L6 逻辑分层​

层内容所有者与边界
L0 SourceERP 交易、Platform 主数据、上传文件ERP/Platform/Storage；Agent 不直连 ORM
L1 Landing解析、标准化、质量画像、导入批次接入边界；做 checksum、病毒和敏感字段检测
L2 SemanticDataset、指标/维度、单位、时区、Lineage、ACL 引用业务数据契约；版本化 allowlist
L3 Snapshot授权后的不可变查询结果和过滤范围Agent Run；TTL、checksum、可回放
L4 Retrieval文档、Chunk、Embedding、索引版本、引用映射RAGFlow 拥有索引内部实现，Agent 保留 ACL 映射
L5 ExecutionSession、Run、Step、Event、Checkpoint、ToolCall、Approval、UsageAgent 运行时；追加日志、租户隔离、保留策略
L6 ResultReport、ChartSpec、Artifact、Citation、导出任务Agent 结果边界；下载重新鉴权

逻辑层不等于七套数据库。首期使用 ERP PostgreSQL、独立 Agent schema、对象存储和可选 RAGFlow 即可。

5. 所有权和保留​

ERP 拥有交易事实和指标口径，Platform 拥有身份、租户和权限，RAGFlow 拥有索引内部数据，Agent 拥有 Run、事件、Snapshot 元数据和结果引用。不同所有者分别管理迁移、备份、删除和保留；不能把 RAGFlow 内部表或模型上下文当作 Agent 事实源。
