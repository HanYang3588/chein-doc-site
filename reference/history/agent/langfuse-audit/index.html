Chein Agent 现有架构与可观测性审计

审计代码基线：fe8ea0274eca2f0ae5c170aa31d0aaa7ac5704c2 及当前工作区。 状态：静态代码审计完成；未运行业务服务或生产测试。本文保留 P1 接入前的审计事实；当前实施状态见 P1–P5 实施。总体设计和实施计划仍为 Proposed；P1 已获用户授权实施，P2–P5 本地实现见 实施与启用，外部验收待完成。

1. 审计范围与前提纠正​

已阅读 Agent 架构、模块化实施基线、前端架构、监控、LangSmith 设计、Langfuse 部署和本次涉及的实现。现有架构事实仍由上述基线维护。

用户报告 Langfuse 页面可访问，这是目标环境的用户提供信息，不是本次验证过的 SDK 写入、Worker 消费或 ClickHouse 落地证据。仓库镜像模板默认 4.56.0，不能据此断言服务器实际镜像/digest、许可、资源和迁移模式。

开始工作时已有修改：deploy/langfuse/langfuse.env.example、docs/deployment/langfuse.md，以及未跟踪的 deploy/langfuse/compose.external.yml。本次保留它们，只增加设计文档及导航。

背景说法核实后的事实证据状态
已有 Langfuse 完整集成Agent 无 Langfuse 依赖或 Callback；Web 可访问不能证明业务接入已通过代码验证；服务器待实验验证
DeepAgents 多子代理、文件和 Skills主 Agent 已创建；通用子代理明确禁用，文件工具隐藏并拒绝读取；未发现 Skills 执行/版本注册接线已通过代码验证
SQL 生成与决策安全审核模型生成结构化 QuerySpec，ERP 编译并校验 SQL AST；没有当前决策模型审查 SQL 的调用链已通过代码验证
RAGFlow 检索、重排与 Judge已有授权 HTTP 检索、RAGFlow 内部重排、Agent 有界查询规划及证据 Judge；重排前排名和独立重排耗时未返回已通过代码验证
Higress 已全面运行聊天/System One 入口可配置；仓库设计记录透传验收待完成，无法确认真实流量经过 Higress已通过代码验证；运行环境待实验验证
后台任务与自动恢复 Worker当前执行在 Agent API 的 SSE generator 内；Run/lease/checkpoint 已有，独立自动 Worker/MQ 未接入已通过代码验证
完整 OTel/SkyWalking有 ECS trace/span 字段和 OTel API 间接依赖，没有已接线的 TracerProvider、HTTP 自动埋点或 SkyWalking Agent已通过代码验证

3. 从用户请求到最终响应的真实流程​

图中阶段并非每次都发生：普通聊天不必调用 Tool/RAG/决策；续问和显式深度思考沿现有决策跳过路径。流式响应和数据库写入交错，不能将模型全部执行结束之后才开始 SSE 画成当前实现。

5. 已有观测与关键缺口​

能力现状设计处理
Request IDBFF 生成，Agent 仅在验证委托后继承；响应 X-Request-ID直接复用，单请求关联，不用作 session
Session / Thread / Run / Message / ToolCall ID已有业务 IDs；Run 分支/恢复语义不同；SSE assistant message_id 每次执行生成复用并增加 execution 引用；禁止假设浏览器消息 ID 就是 checkpoint ID
Trace / Span IDECS 字段预留；Knowledge 单独业务 trace UUID；没有统一 OTel 生成传播区分业务 retrieval_id 与 32 hex OTel trace_id
LangChain/LangGraph callback每次 astream 新建 MetadataLogCallback；不观察完整 graph state保留；每执行新增 Langfuse handler，不全局共享有状态 handler
Token / 耗时LLM/Tool 元数据有部分 Token、调用耗时；决策/检索各有局部 elapsed统一 usage 来源与缺失口径，补浏览器 TTFT 与执行耗时
错误与 ESHTTP、流式执行、模型/工具异常有脱敏记录；运行日志管理页已实现Langfuse 不复制堆栈与正文；全量错误从现有日志/Run 状态观察
PrometheusBackend 有 HTTP/进程指标，ERP 有命令指标；Agent 无独立指标接线P2/P3 增加 Agent 低基数指标，复用监控基础设施；现有 HTTP 指标不是完整 SSE 时长
质量反馈Knowledge 证据反馈及离线 evaluator 已有；未发现点赞/点踩到后端/Score 的链路P4 接线；不能把 assistant-ui 组件库支持解释成已上线反馈

Usage 根因已通过锁定版本源码验证：langchain-openai 1.6.2 在自定义 base_url 情况下不自动启用 stream_usage；Chein 显式配置了 base_url 且未传 stream_usage。因此不能承诺聊天流返回真实 Usage。需要 P1 用真实兼容端点验证显式 usage 支持，失败时标缺失，而非改用文本估算冒充实际值。官方参数说明。
