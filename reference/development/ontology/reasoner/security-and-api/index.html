安全与 API 契约

架构入口见计算服务设计，机器可读契约为 services/chein-reasoner/openapi.yaml，正式业务 OpenAPI 仍由 Backend 生成。

身份与授权​

前端只请求现有同源 Backend，不接收 Java 凭据。Higress 路由只指向 Backend，Java 不提供公网业务路由，内部 Docker 网络与容器端口不发布。网关 External Auth 可复用 Backend 的当前会话验证入口，必须 failure_mode_allow=false；即使网关验证通过，Backend 仍按 ModuleDefinition + 当前用户/租户/资源重验。

复用 ontology:query 提交/取消，ontology:read 查询/结果/导出；不新增重复 RBAC 表，网络 private/tenant 和数据权限继续由数据所有者判断。任务只归 tenant/owner，管理员不因此读取他人结果。版本引用每次读取重验 runtime.authorized_snapshot、正文摘要和完整映射可见性；不能混入未授权 TBox 后再过滤结果。

Backend 用 Ed25519 签发短期 token，优先配置专用 reasoner 私钥，也允许显式复用既有 delegation 密钥；Java 只持有公钥。issuer=chein-backend、audience=chein-reasoner、sub=当前 owner、tenant_id、scope、iat/exp/jti，绑定 HTTP method/path、Idempotency-Key 和原始请求 body SHA256。有效期最多 60 秒，登录 HS256、Agent audience、过期、未来签发、缺字段、错误算法、伪造 tenant/user header 均拒绝。Java 使用 JDK Signature Ed25519 验签及严格有界 JSON/JWT 结构校验；这不复制用户登录或授权目录。TLS 由内部代理/网格终止，直连 HTTP 只允许显式本地/私网配置；生产建议 mTLS，签名不替代传输保密。

业务匿名401、scope不足403、他人或未知任务统一404、未就绪503、队列满429、幂等冲突409、非法输入422、过大413。健康只公开 liveness/readiness 的最小 UP/DOWN，不公开环境、配置、heap dump。指标和管理路径需单独 manage scope。服务身份组件异常失败关闭。

OWL 安全​

只从有界字符串加载，不接受 URL、文件路径、Java 类名、脚本、任意 Cypher。固定三种格式解析器；XML 先用禁 DTD/外部实体的 JAXP 校验。Import 通过拒绝型 IRIMapper 失败，不静默忽略；XML/Turtle/Functional 的外部资源负向测试必须实际运行。解析及 HermiT 全部在有限堆子 JVM，环境不继承 Nacos/模型/数据库密钥，stdout/stderr 不回传正文或异常堆栈。输出也有限额，未知异常只返回固定代码。日志仅 request/job/status/duration，禁止业务正文、Token、endpoint credential 和用户姓名；指标无 tenant/owner 高基数字段。

第一阶段 private volume 必须仅服务账号读写，磁盘加密/备份由运维提供；TTL 删除不是安全擦除。高风险多租户部署还应使用 OS/network sandbox 限制 worker 权限，不能把 Java thread cancel 当安全隔离。

REST​

Backend 路由 /api/v1/ontology/reasoner：

  • POST /jobs：版本引用 {network_id,version} 或上传 {content,format}，operation 与固定查询参数；必需 Idempotency-Key UUID；202。
  • GET /jobs/{id}：本人状态，返回 jobId/ontologyVersion/inputDigest/operation/status/metrics/errorCode，不默认含结果或输入。
  • GET /jobs/{id}/results?offset=0&limit=100：成功后有界查询结果；未完成409，未知/无权404。
  • POST /jobs/{id}/cancel：幂等取消，终态保持不变。
  • GET /jobs/{id}/export?format=json|turtle|rdfxml：有界查询结果导出，不是全量事实物化。
  • consistency/classify/instances/property-values/entailment 便捷 POST 仍创建同一种异步任务，不产生第二套同步执行器。

validate-rules 保持仅 TBox，拒绝实例；画布发布使用新增 validate-ontology 对完整 TBox/ABox 校验。两者均拒绝未解析三元组、远程 Import、SWRL 和 OWL 2 DL Profile 之外的内容，并返回不可满足类。构建器要求本人任务成功、一致、未截断且不可满足类为空，完整输入摘要须与当前草稿相同；不放宽原有规则发布门禁。

内部 Java 对应 /internal/reasoner/v1/jobs；GET/取消/结果需要短期 token，真实 identity 只读已验签 claims；ontologyVersion 是 Backend 构造的来源引用而非客户端的身份断言。原始上传引用 upload:<sha256>；已发布引用包含 network UUID、version、definitionDigest、catalogDigest。

一致性响应 consistent 为布尔；不可满足类是独立集合。层次/类型/对象属性查询为稳定排序 IRI 列表；分页标记 total/truncated。蕴含采用固定类型 subclass/class-assertion/object-property-assertion，未蕴含标记 false 并注明开放世界。结果元数据区分 query、asserted 与 query-result graph；不把整个查询输出都称为新增公理。

本地 Swagger 文档​

REASONER_DOCS_ENABLED 默认 false，npm run dev:reasoner 默认开启。启用后只允许静态文档页面、明确列出的 Swagger 资源和 /v3/api-docs.yaml 的 GET 免鉴权；关闭时这些路径返回404。未扩大业务、Actuator 或任意 /swagger-ui/** 路径的匿名权限。UI 使用本地 WebJar 资产，关闭在线校验、URL查询配置覆盖和授权持久化；源契约只维护 services/chein-reasoner/openapi.yaml，构建时直接打包。

内部 Swagger 的 Try it out 仍要求与实际 method/path/body/idempotency 一致的短期 delegation，不能使用普通登录Token；不在浏览器放私钥或新增免授权签名接口。正常业务调试走既有 Backend /docs 的 ontology 路由，以现有登录/当前租户/资源权限执行。
