技术选择与依赖

2026-10-26，先进行仓库外 Java21/Maven/HermiT 兼容探针，再固定实现。实测固定：Spring Boot 3.5.16、OWL API 5.5.1、HermiT net.sourceforge.owlapi:org.semanticweb.hermit:1.4.5.519、Nacos Java Client 3.2.4；真实 Java21 构建、推理和 Nacos Server3.2.4 实测已通过，详见验证记录。

Spring Boot 3.5 系统要求支持 Java21。SCA 官方矩阵将 2025.0.0.0 对应 Boot3.5.0/Cloud2025.0.0/Nacos3.0.3；它不是当前 Server3.2.4 已验证的证据。服务只需要 Naming/Config，选择官方 Nacos Java SDK直连，避免引入整套 Spring Cloud/Alibaba 自动配置及版本耦合。Nacos 注册在 ApplicationReady 后，关闭时先拒绝新任务、注销、结束 Worker；可选启动配置仅读取 CHEIN/chein-reasoner-runtime.properties 固定白名单，失败不能安全降级；默认无动态热更新。

OWL API支持 OWL2 和 RDFXML/Turtle/Functional；5.5.1 替代 HermiT 旧传递版本，必须实测而不是假设二进制兼容。OWLCS HermiT 分发是 OWLAPI 团队适配版；Maven1.4.5.519 并非近期维护的新引擎，版本陈旧有维护风险。不要将官网1.3.8、未发布1.4.6 snapshot 与所用发行包混淆。

许可证：HermiT 元数据为 LGPL3，包含的 Jautomata 及第三方告知也须保留；OWL API 为 Apache/LGPL 双许可，Spring/Nacos 为 Apache2。必须交付第三方声明、所用版本与源码获取链接、LGPL 正文和修改/替换义务说明，不能断言无条件闭源商用。未修改 HermiT 核心，不移除版权；发布前法务审阅和安全扫描独立门禁。依赖树、CycloneDX SBOM 与漏洞报告由 Maven 命令生成；排除未使用的历史 logging/XML 实现不等于所有传递依赖安全。

本机 JDK21 为 ARM GraalVM21.0.3（默认 java 指向不能执行的 Intel JDK8）。构建脚本显式要求 JAVA_HOME 的 Java21，镜像使用 Temurin21；不改整个仓库或用户全局 JDK。老旧本地 JDK 补丁版本不是生产镜像安全验收。

新服务的安全修复版本​

OSV 按 SBOM 包版本查询后，当前新服务在 Boot BOM 上显式固定 Jackson 2.21.8、Tomcat 10.1.61、Log4j 2.25.5、OpenTelemetry 1.62.0、HttpClient5 5.6.5 / HttpCore5 5.4.4。这些只作用于新增 Maven 模块；必须再次真实构建、推理与 HTTP 验证。最终剩余匹配见验证记录，不把包匹配等同于可利用性，也不忽略它。
